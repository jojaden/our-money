# SplitBar — 월급이 나뉘는 곳

플랜 화면의 "월급이 나뉘는 곳" 카드입니다. 수입이 고정비·생활비·용돈·저축·남음으로 어떻게 나뉘는지 **수입 큰 숫자 + 한 줄 쌓은 막대 + 금액 목록**으로 보여 줍니다(README "숫자와 막대": 전체를 나눈 몫). 예전 원형 그래프는 자리를 많이 쓰면서 답 숫자(수입)를 가운데 작은 글씨로 밀어내서 바꿨습니다.

## 구성 (위에서 아래로)
- **세그먼트** `[두 사람 | 현빈 | 예진]`: 사람을 고르면 그 사람 월급과 몫(`shareOf`, 공동 항목은 비율만큼)으로 다시 그립니다.
- **답 숫자:** 이름표 "두 사람 수입"(`faint` 15px)과 수입(`display` 34px, "원"은 22px). 가계부 "이번 달 누적 지출"과 같은 `hero-label`·`hero-amt`입니다.
- **결론 한 줄:** "**926,100원** 남았어요 · 수입의 87%를 나눴어요"(`faint`, 금액은 `text` 600). 넘치면 "수입보다 **120,000원** 더 나눴어요"(금액 `negative`), 수입이 없으면 "아직 이번 달 수입을 적지 않았어요." 화면 머리에 따로 결론 문장을 두지 않습니다.
- **쌓은 막대:**
  - 높이 12px, 양 끝 `radius-chip`, 조각 사이 2px 틈(카드 바탕이 비침). 조각 폭은 금액에 비례하고, 아주 작은 조각도 3px은 보입니다.
  - 순서는 고정비(`g-fixed`) → 생활비(`g-living`) → 용돈(`g-allowance`) → 저축(`g-saving`) → 남음(`g-left`)입니다. **버킷 색은 이 막대와 목록 점에만** 씁니다.
  - 배분이 수입보다 많으면 막대 한 줄을 배분 합계로 삼고 남음 조각을 빼며, 수입 자리에 진한 눈금(2px `text`, 위아래 4px)을 긋습니다.
- **목록:** 점(10px) · 이름 · 비율(`faint`) · 금액 · 펼침 화살표. 남음은 펼치지 않습니다. 모자라면 이름이 "부족", 금액이 `negative`입니다.
- **아래 한 줄:** 두 사람이면 "공동비용은 50 : 50로 나눠요", 한 사람이면 "현빈 공동 부담 2,196,450원"(`faint`).

## 고르기
- **목록의 이름을 누르면** 그 줄에 `well` 바탕이 깔리고, 막대에서 그 조각만 남기고 나머지가 30%로 옅어지며, 줄 아래에 버킷 항목(이름 · 공동/누구 · 금액, 큰 순)이 펼쳐집니다. 다시 누르면 접히고 막대도 돌아옵니다. 항목을 누르면 항목 시트가 열립니다.
- 막대는 누르는 곳이 아닙니다(12px라 손가락 자리가 안 됨). 같은 일을 목록이 합니다.
- 사람을 바꾸면 고른 것과 펼친 것을 모두 닫습니다.

## 움직임·접근성
- 움직이는 것은 조각의 `opacity`와 화살표 `transform`뿐이고 `dur-swap`입니다. `prefers-reduced-motion`이면 바로 바뀝니다.
- 막대는 `aria-hidden`이고, 같은 내용을 목록 버튼(`aria-expanded`, 남음은 `aria-pressed`)이 이름·비율·금액으로 말합니다. 색만으로 버킷을 말하지 않습니다.

## 하지 말 것
- 원형·도넛 그래프로 되돌리지 않습니다.
- 수입 숫자를 막대보다 작게 쓰거나 막대 안에 글자를 넣지 않습니다.
- 버킷 색을 이 카드 밖(예산 막대, 하루 막대)에 쓰지 않습니다.

## 다른 달에서 항목 가져오기
- 플랜 화면 맨 아래 한 줄 카드(`Download` 아이콘 · "다른 달에서 항목 가져오기" · "지운 항목을 되살리거나 예전 달 항목을 다시 넣어요" · ›)입니다. 데스크톱은 왼쪽 열 끝, 폰은 맨 끝(`o8`). 이 달 플랜이 있고 다른 달이 있을 때만 보입니다. 누르면 ImportSheet가 열립니다.
