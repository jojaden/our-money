# Login

로그인 화면입니다. Alan 첫 화면("Hello!")처럼 따뜻한 무대 가운데에 브랜드 동전을 띄우고, 반가운 인사 한 줄과 아래쪽 버튼 하나로 끝냅니다. 앱의 `Gate` 화면(로그인 전, 등록 안 된 계정)을 대신합니다.

## 구성
- **무대:** Loading과 같습니다. 원형 그라데이션 바탕, 지붕과 겹친 두 동전, 바닥 그림자, 곁의 금빛 동전 둘입니다. 무대는 화면 위쪽(위 여백 70px, 높이 330px)에 둡니다.
- **인사:** 가운데 정렬입니다.
  - 제목: 28px/700 "반가워요!"
  - 설명: `muted` 17px/26px, `text-wrap: balance`. "우리 집 가계부에서 두 사람의 한 달 돈을 함께 챙겨요"
- **버튼:** 화면 맨 아래(좌우 `edge`, 아래 30px + 안전 영역)에 둡니다.
  - 주 버튼은 꽉 찬 `primary`, `control-height`, `radius-control`입니다. `LogIn` 아이콘과 함께 "구글 계정으로 로그인"이라고 씁니다.
  - 그 아래 `meta`·`faint`로 "등록된 두 사람의 구글 계정만 들어올 수 있어요"라고 적습니다.

## 등록 안 된 계정
- 무대는 그대로 두고 글과 버튼만 바꿉니다.
  - 제목: "등록되지 않은 계정이에요"
  - 설명: "someone@example.com 계정은 이 가계부에 연결되어 있지 않아요". 메일 주소는 `text` 600입니다.
- 버튼은 흰 보조 버튼("다른 계정으로 로그인", `surface` 바탕, `accent-ink` 글자, `shadow-card`) 하나입니다. Alan의 "Subscribe" 버튼과 같은 모양입니다.
- 아래 줄은 "멤버로 등록된 구글 계정으로 다시 로그인해 주세요"입니다.
- 관리자용 안내("Supabase의 members에서 바꾸기")는 이 화면에 두지 않습니다. 설정이나 문서로 보냅니다.

## 앱에서
- **연결 실패:** "연결할 수 없어요" / "데이터를 불러오지 못했어요"도 같은 무대에 제목·설명과 주 버튼 "다시 시도" 하나로 보여 줍니다.
- **상태 막대:** 무대가 떠 있는 동안 `theme-color`를 `warm-100`으로 바꿔, 홈 화면 앱에서 무대가 상태 막대까지 이어집니다(edge-to-edge). 무대는 화면 끝까지 그리고 글과 버튼은 안전 영역 안에 둡니다.
- **화면 크기(adaptive):**
  - 폰 세로: 무대 위 여백 70px, 버튼은 맨 아래(엄지 자리)입니다.
  - 낮은 화면(높이 620px 이하, 가로 폰): 무대를 72%로 줄이고 위 여백을 12px로 좁혀 글과 버튼이 한 화면에 들어오게 합니다.
  - 넓은 화면(폭 720px 이상): 엄지 자리가 의미 없으므로 버튼을 글 바로 아래(36px)에 두고 전체를 화면 가운데로 모읍니다.

## 움직임
- 브랜드 동전이 `dur-breathe` 박자로 6px 떠올랐다 내려오고, 바닥 그림자가 같이 줄었다 커집니다(`ease-breathe`).
- 계속 움직이는 것은 이것 하나입니다.
- 움직임 줄이기 설정이면 멈춥니다.
- 떠오르기와 그림자 모두 `transform`·`opacity`만 바꿔, 레이아웃을 다시 계산하지 않고 합성 단계에서만 움직입니다(jetpack-compose-performance의 "그리기 단계로 미루기"와 같은 원리).

## 하지 말 것
- 버튼을 셋 이상 두지 않습니다. 이 앱은 가입이 없어서 주 버튼 하나면 됩니다.
- 무대에 앱 이름 글자를 크게 넣지 않습니다. 이름은 설명 문장 안에 둡니다.
- 마스코트, 사진, 3D 캐릭터를 넣지 않습니다.
- 버튼을 무대 가까이 올리지 않습니다. 엄지가 닿는 아래쪽에 둡니다.
