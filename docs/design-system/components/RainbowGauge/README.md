# RainbowGauge

이번 달 네 버킷(고정비·생활비·용돈·저축)의 사용률을 겹친 반원 호로 한눈에 보여 주는 가계부 페이지의 머리 게이지입니다. 홈 머리는 BudgetCard 큰 카드(생활비 하나)가 맡습니다. 호는 Alan Walk의 무지개 게이지처럼 빛을 받은 튜브 모양입니다.

## 구성
- **호:**
  - 바깥에서 안으로 `g-fixed`, `g-living`, `g-allowance`, `g-saving` 순서입니다.
  - 반지름은 140 / 121 / 102 / 83, 선 굵기 14px, 호 사이 5px, 둥근 끝입니다.
- **튜브 질감(세 겹):**
  - 테두리(14px)는 버킷 색에 `text`를 10% 섞습니다.
  - 몸통(12px)은 버킷 색입니다.
  - 가운데 빛(5px)은 `surface` 50%에 1px 흐림입니다.
  - 빈자리도 같은 세 겹입니다. 테두리는 `lilac` 85%, 몸통은 `lilac` 42%, 빛은 `surface` 90%라서, 버킷 색과 상관없이 옅은 라일락빛 흰 튜브로 보입니다.
  - 게이지 전체에 `accent-ink` 10% 그림자(아래 6px, 흐림 10px)를 깝니다.
- **호 가운데:** 전체 사용 %(Alan Sans 800, 40px, "%"는 0.5em `faint`)와 "예산 사용"(`caption`)입니다. 눈금 점이나 "0"·"100%" 글자는 두지 않습니다.
- **바탕과 패널:**
  - 바탕은 `sky-100` → `glow` 세로 그라데이션입니다.
  - 위에는 달 알약("11월 · 21일 남음")을 둡니다.
  - 흰 곡선 패널(가로 50% / 세로 30px 모서리)이 가장 안쪽 호의 다리 바로 아래까지 올라옵니다.
- **패널 안:**
  - 가운데 "이번 달 쓴 돈", `figure` 금액, "예산 4,700,000원"입니다.
  - 그 아래 버킷 줄입니다. 줄은 두 줄짜리입니다.
    - 첫 줄: 색 점 10px과 이름(`row-title`)
    - 둘째 줄: "1,320,000 / 1,500,000원"(`faint`, 고정폭)
    - 오른쪽: %(Alan Sans 600, 17px)
  - 줄 사이는 0.6px `rule` 선으로 나눕니다.

## 움직임
- 처음에는 0에서 `dur-ring`·`ease-out`으로 그립니다.
- 값이 바뀌면 이전 값에서 새 값으로 `dur-value`·`ease-value`로 이어 갑니다. 세 겹은 같은 값으로 함께 움직입니다.
- 가운데 %와 금액도 같은 시간에 같이 바뀝니다.
- 움직임 줄이기 설정이면 바로 끝 값을 보여 줍니다.

## 예산 초과
호를 100%에서 멈추고 그 줄의 %를 `negative`로 씁니다.

## 쓰는 쪽이 줄 것
- 버킷마다 예산과 쓴 돈, 달과 남은 날 수

## 하지 말 것
- 버킷을 다섯 개 넘게 겹치지 않습니다.
- 호 색을 버킷 색과 다르게 칠하지 않습니다. 튜브의 테두리를 진하게 해서 외곽선처럼 만들지 않습니다.
- 값이 바뀔 때 처음부터 다시 그리지 않습니다.
- 가계부 페이지 말고 다른 곳에 두지 않습니다. 홈에 두면 생활비 큰 카드와 반원 호가 겹칩니다.
