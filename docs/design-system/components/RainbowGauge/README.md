# RainbowGauge

이번 달 쓴 돈 버킷(공동 생활비·두 사람 용돈)의 사용률을 겹친 반원 호로 한눈에 보여 주는 가계부 페이지의 머리 게이지입니다. 홈 머리는 BudgetCard 큰 카드(생활비 하나)가 맡습니다. 호는 Alan Walk의 무지개 게이지처럼 빛을 받은 튜브 모양입니다.

- **왜 두 겹인가:** 가계부는 지출 기록의 화면입니다. 고정비·저축은 지출 기록이 아니라 체크(납부·이체 완료)로만 알 수 있어서 체크 화면이 맡습니다. 두 버킷만 겹치면 가운데 "이번 달 쓴 돈"이 아래 기록 목록의 합계와 같아집니다.

## 구성
- **호:**
  - 바깥에서 안으로 `g-living`, `g-allowance` 순서입니다.
  - 반지름은 136 / 113, 선 굵기 18px, 호 사이 5px, 둥근 끝입니다.
- **튜브 질감:** README "게이지와 막대"의 빛을 머금은 튜브입니다. 호마다 옅은 버킷 색에서 진한 끝으로 번지고, 굵기 방향 입체를 덧씌우고, 둘레에 같은 색 빛(선보다 6px 굵게, 5px 흐림)이 돕니다. 끝에는 테두리 없는 흰 점(지름 10px)입니다. 빈자리는 옅은 회색 튜브입니다.
  - 게이지 전체에 `accent-ink` 10% 그림자(아래 6px, 흐림 10px)를 깝니다.
- **호 가운데:** 전체 사용 %(Alan Sans 800, 40px, "%"는 0.5em `faint`)와 "예산 사용"(`caption`)입니다. 눈금 점이나 "0"·"100%" 글자는 두지 않습니다.
- **바탕과 패널:**
  - 바탕은 `sky-100` → `glow`(55%) → `surface` 세로 그라데이션으로, 가장 안쪽 호의 다리 아래에서 흰 바탕으로 이어집니다. 가르는 선이나 곡선은 두지 않습니다(BudgetCard 큰 카드와 같은 틀).
- **패널 안:**
  - 가운데 "이번 달 쓴 돈", `figure` 금액, "예산 2,200,000원"입니다.
  - 그 아래 속도 알약으로 생활비를 지난달 같은 날까지와 견줍니다("생활비를 지난달 이맘때보다 10% 덜 썼어요"). 지난달 기록이 없으면 두지 않습니다.
  - 그 아래 버킷 줄입니다. 줄은 두 줄짜리입니다.
    - 첫 줄: 색 점 10px과 이름(`row-title`)
    - 둘째 줄: "390,000 / 1,400,000원"(`faint`, 고정폭). 두 사람 용돈은 셋째 줄에 "현빈 121,300 · 예진 73,000"을 더합니다.
    - 오른쪽: %(Alan Sans 600, 17px)
  - 줄 사이는 0.6px `rule` 선으로 나눕니다.

## 움직임
- 처음에는 0에서 `dur-ring`·`ease-out`으로 그립니다.
- 값이 바뀌면 이전 값에서 새 값으로 `dur-value`·`ease-value`로 이어 갑니다. 채운 호, 그라데이션 끝, 끝 점은 같은 값으로 함께 움직입니다.
- 가운데 %와 금액도 같은 시간에 같이 바뀝니다. 쓴 돈과 예산을 함께 보간하므로 예산만 바뀌어도 호와 %가 이어집니다.
- 첫 실제 프레임부터 시간을 재며, 월 이동은 공통 월 전환 규칙(사라짐 → 데이터 교체 → 나타남)을 따릅니다.
- 움직임 줄이기 설정이면 바로 끝 값을 보여 줍니다.
- 구현을 바꿔도 증가·감소 양방향의 움직임을 유지하며, [공통 움직임 유지와 회귀 검증](../../README.md#움직임-유지와-회귀-검증)에 따라 실제 브라우저의 중간 프레임까지 확인합니다.

## 예산 초과
호를 100%에서 멈추고 그 줄의 %를 `negative`로 씁니다.

## 쓰는 쪽이 줄 것
- 버킷마다 예산과 쓴 돈, 지난달 같은 날까지의 생활비

## 하지 말 것
- 고정비·저축처럼 지출 기록으로 알 수 없는 버킷을 겹치지 않습니다.
- 호 색을 버킷 색과 다르게 칠하지 않습니다. 진한 테두리나 가운데 흰 띠를 겹치지 않습니다.
- 값이 바뀔 때 처음부터 다시 그리지 않습니다.
- 가계부 페이지 말고 다른 곳에 두지 않습니다. 홈에 두면 생활비 큰 카드와 반원 호가 겹칩니다.
