# TextTabs

기간이나 보기 방식처럼 같은 자료를 다른 범위로 보는 선택지를 글자만으로 늘어놓는 탭으로, 고른 칸만 옅은 노랑 알약이 감쌉니다.

## 언제 쓰나
- 오늘 / 이번 주 / 이번 달 / 올해, 또는 체크 화면의 "현빈 / 예진 / 공동" 보기처럼 범위를 바꿀 때 씁니다.
- 결제 수단처럼 값을 입력하는 선택은 Segmented를 씁니다.

## 구성
- **칸:** 높이 36px, 글자 14.5px입니다. 안 고른 칸은 바탕 없이 `faint`입니다.
- **고른 칸:** `accent-soft` 알약에 `accent-ink` 600입니다. 바뀔 때 `dur-press`로 바탕과 글자색이 바뀝니다.
- **위치:** 탭 위에 섹션 이름표(`small`·`faint`)를 두고, 바로 아래 카드가 고른 범위를 보여 줍니다.

## 쓰는 쪽이 줄 것
- 선택지 이름, 고른 값

## 하지 말 것
- 다섯 칸을 넘기지 않습니다.
- 안 고른 칸에 바탕이나 테두리를 두지 않습니다.
