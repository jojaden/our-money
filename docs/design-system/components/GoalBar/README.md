# GoalBar

모으는 돈의 목표 대비 진행을 "모은 돈 / 목표"와 얇은 막대로 보여 주는 카드입니다.

## 언제 쓰나
- 적금·비상금처럼 끝 금액이 있는 목표에 씁니다.
- 목표 금액의 상한은 `MAX_GOAL`을 따릅니다.

## 구성
- **카드:** 제목(`headline`)과 한 줄 설명(`faint`)입니다.
- **안쪽 목표 블록:** `radius-inner`, `shadow-card` 링입니다. 안에 세 줄을 둡니다.
  - "목표"와 목표 금액(`display` 18px/700)
  - `accent-ink` 모은 돈과 `faint` "/ 목표 · %"
  - 6px 막대: `well` 트랙에 `primary` 채움, 둥근 끝
- **움직임:** 처음에는 0에서 `dur-ring`으로 차오르고, 값이 바뀌면 `dur-value`·`ease-value`로 이어 갑니다.
- **접근성:** 막대는 `role="progressbar"`에 최소·최대·현재 값을 줍니다.

## 쓰는 쪽이 줄 것
- 목표 이름, 기한이나 계좌 설명, 목표 금액, 모은 돈

## 하지 말 것
- 막대를 6px보다 두껍게 하지 않습니다.
- 목표를 넘었을 때 막대를 넘치게 그리지 않습니다. 100%에서 멈추고 "목표 달성"을 `pill-positive`로 붙입니다.
