# Nudges — 홈 맨 위 알림

홈 화면 머리 문장 대신, 지금 알아야 할 것을 **토스 알림처럼 하나씩 작게서 커지며 도착하는 카드**로 보여 줍니다. 화면 머리에는 달과 기간만 둡니다(README "글자").

## 무엇을 띄우나 (중요한 순, 최대 3개)
| 알림 | 색 | 아이콘 | 누르면 |
|---|---|---|---|
| "현빈 ISA로 옮길 돈 외 2건이 기한을 넘겼어요" | `negative` | `CircleAlert` | 체크 |
| "관리비 외 1건이 잘 나갔는지 확인해 주세요" (자동 납부) | `neutral` | `CircleHelp` | 체크 |
| "오늘은 예진 월급날이에요 · 옮길 돈 1건 100,000원" | `positive` | `Banknote` | 체크 |
| 월급날이 아니면 "옮길 돈 2건이 남았어요 · 600,000원" | `neutral` | `ArrowRightLeft` | 체크 |
| "이번 달 이체와 납부를 모두 마쳤어요" | `positive` | `CircleCheck` | 체크 |
| "생활비가 예상보다 120,000원 빨리 나가고 있어요" | `warning` | `TrendingUp` | 가계부 |
| 옮길 돈 알림이 없을 때만 "다음은 현빈 월급날 11/25 · D-15" | `neutral` | `CalendarClock` | 체크 |

할 일 카드와 겹치는 "남은 할 일 N건"뿐이면 알림을 두지 않습니다.

## 카드
- 흰 카드(`surface-card`, `shadow-card`), 위아래 14px. 아이콘 원(36px, 상태 알약과 같은 `pill-*-bg` 바탕·`pill-*-ink` 아이콘) · 한 줄(15.5px/500, 강조는 700) · `ChevronRight`(`faint`).
- 카드 사이와 아래 카드까지는 `gap`. 알림이 없으면 자리와 간격까지 0입니다(ClosePrompt와 같은 방식).

## 도착
1. 덜 중요한 알림부터 차례로 도착합니다(첫 알림은 250ms 뒤, 다음은 700ms 간격). 새 알림은 늘 맨 위에 생기므로 다 도착하면 가장 중요한 알림이 맨 위입니다.
2. **작게 → 크게 (520ms):** 카드와 글이 한 덩어리로 20% 크기·투명에서 커지며 나타나 103%까지 살짝 넘쳤다가 제자리에 앉습니다(`transform`·`opacity`만, 가운데 기준). 색이 번쩍이거나 카드가 먼저 펴지고 글이 뒤에 나오지 않습니다.
3. **먼저 온 알림은 아래로:** 새 알림 자리만큼 먼저 온 알림과 아래 카드들이 `dur-tab`·`ease-drawer`로 내려갑니다(`Morph`의 FLIP과 상자 높이).
4. 앱을 켜 둔 동안 한 번 도착한 알림 종류는 탭을 다시 열어도 다시 움직이지 않고 그대로 있습니다. 사라진 알림은 `Morph`가 흐리게 지우고 아래 알림이 올라옵니다.
5. 움직임 줄이기면 모두 바로 보입니다.

## 하지 말 것
- 알림을 4개 이상 쌓지 않습니다.
- 카드를 아래에서 올라오게 하거나, 카드 바탕을 먼저 펴고 글을 나중에 띄우지 않습니다. 도착 순간 알림 색을 번쩍이지 않습니다.
- 같은 알림을 탭을 열 때마다 다시 도착시키지 않습니다.
