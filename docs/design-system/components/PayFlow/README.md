# PayFlow

두 사람 월급이 어느 버킷으로 나뉘는지 한 사람에 막대 하나씩 보여 주는 카드입니다("두 사람 월급의 흐름"). 앱의 `LaneBar`·`LaneKey`를 대신합니다.

## 구성
- **머리:** 카드 이름(`headline`)과 "플랜 보기 ›"입니다.
- **사람 줄:**
  - 사람 표시는 30px 동그라미(`a-soft`/`b-soft`) 안의 **동전 반쪽**입니다. 현빈은 왼쪽 반, 예진은 오른쪽 반이 사람 색으로 채워지고 나머지 반은 `control` 선입니다(앱의 `PersonGlyph`).
  - 이니셜은 쓰지 않습니다. 두 사람 이름이 같은 글자로 시작할 수 있습니다.
  - 그 옆에 이름(`row-title`), 오른쪽에 월급을 `display` 600으로 씁니다.
- **막대 (이어 붙인 튜브):**
  - 14px 높이 캡슐 하나에 버킷 조각을 이어 붙입니다. 조각 사이 2px으로는 카드 바탕이 비쳐 보입니다.
  - 순서는 고정비 → 생활비 → 용돈 → 저축 → 남음(`g-left`)입니다. 아주 작은 조각도 4px은 남깁니다.
  - 캡슐 위에 튜브 빛을 덮습니다. 위쪽 `surface` 55%가 아래로 사라지는 세로 그라데이션과, 아래 안쪽 그림자(`text` 12%)입니다.
  - 두 막대는 같은 자로 잽니다. 많은 쪽 월급이 막대 끝이고, 적은 쪽 캡슐은 그만큼 짧습니다.
- **아래 줄:** 평소에는 "공동 부담 2,196,450원"과 "남음 661,550원"(금액은 `text` 700)입니다.
- **범례:**
  - 막대들 아래 0.6px `rule` 선 밑에 "● 고정비 ● 생활비 ● 용돈 ● 저축 ○ 남음"을 `meta` 크기로 한 줄에 고르게 둡니다.
  - 범례가 곧 고르기 버튼입니다.
  - 그 아래 "막대 길이는 두 사람 중 큰 금액(3,800,000원)에 맞춰요"(`meta`·`faint`)를 적습니다. 배분이 월급보다 많으면 자의 끝은 배분이라 "월급" 대신 "큰 금액"이라고 씁니다.

## 버킷 고르기
- 범례 항목이나 막대 조각을 누르면 두 막대에서 그 버킷 조각만 남고 나머지 조각은 22%로 옅어집니다(`dur-tab`·`ease-out`).
- 고른 범례는 `accent-soft` 알약에 `accent-ink` 600입니다.
- 아래 줄은 "● 고정비 930,000원 · 월급의 24%"로 바뀝니다. 같은 버킷을 두 사람 사이에서 바로 비교할 수 있습니다.
- 같은 항목을 다시 누르면 전체로 돌아갑니다.
- 아래 줄은 `aria-live="polite"`라 바뀐 금액을 읽어 줍니다.

## 배분이 월급보다 많을 때
- 막대는 배분한 만큼 그리고, 월급 자리에 `text` 색 2px 세로 눈금을 막대 위아래로 4px 넘치게 긋습니다.
- 아래 줄 오른쪽은 "부족 120,000원"(`negative`)입니다.
- 넘친 몫을 따로 빨간 조각으로 덧붙이지 않습니다. 덧붙이면 막대가 실제 배분보다 길어집니다.

## 움직임
- **앱을 열고 처음 볼 때만:** 캡슐이 왼쪽에서 오른쪽으로 펼쳐집니다(`clip-path`, `dur-ring`·`ease-out`). 두 번째 사람은 120ms 늦게 시작합니다. 탭을 다시 열 때마다 되풀이하지 않습니다.
- **금액이 바뀔 때:** 조각 길이가 `dur-value`·`ease-value`로 이어서 바뀝니다.
- 움직임 줄이기 설정이면 끄고 끝 상태를 보여 줍니다.

## 플랜에서
- 플랜의 "월급이 나뉘는 곳"도 같은 막대(사람 줄·막대·아래 줄)를 씁니다. 고르기 범례는 홈에만 둡니다.

## 쓰는 쪽이 줄 것
- 사람마다 월급, 버킷별 배분(`lanes()`의 `byGroup`), 공동 부담, 남음

## 접근성
- 막대마다 `role="img"`이고, 이름에 전체 내역을 담습니다: "현빈 월급 3,800,000원: 고정비 930,000원, …, 남음 661,550원".
- 범례는 `aria-pressed` 버튼 묶음입니다. 조각 누르기는 범례와 같은 일을 하는 지름길입니다.

## 하지 말 것
- 조각 안이나 위에 금액 글자를 얹지 않습니다. 조각이 좁아 글자가 잘립니다. 금액은 버킷을 골라 아래 줄로 봅니다.
- 조각을 따로 떨어진 알약으로 늘어놓지 않습니다. 한 사람의 월급은 하나의 캡슐입니다.
- 사람마다 다른 자로 재지 않습니다. 월급이 다른데 막대 길이가 같으면 비교가 틀어집니다.
- 버킷 색을 사람 색으로 바꾸지 않습니다.
