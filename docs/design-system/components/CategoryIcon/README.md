# CategoryIcon — 분류 아이콘

지출 줄(가계부 최근 기록·모든 기록·홈·달력·모아 보기), 분류별 예산, 지출 시트의 분류 칩 앞에 붙는 동그라미입니다. 코드: `apps/web/src/components/CatGlyphs.tsx`(그림), `CategoryIcon`(`components/ui.tsx`), 색·고르기 `lib/categories.ts`.

- **그림:** 외곽선이 아니라 **채운 실루엣 하나 + 흰 디테일**입니다(24×24, 실루엣은 `currentColor` = 분류 색, 디테일은 `on-dark`). 바구니의 살, 컵의 슬리브, 자동차 유리창, 티켓의 별처럼 디테일은 한두 개만 둡니다. 얇은 선·그림자·그라데이션은 쓰지 않습니다.
- **원:** 40px(작게 32px), 완전한 원(`50%`). 바탕은 분류 색을 `cat-tint`만큼 `cat-base`에 섞습니다 — 라이트는 흰 원에 15%(옅은 파스텔), 다크는 `well`에 8%(거의 무채색이라 아이콘 색이 뜸). 그림은 24px(작게 19px).
- **분류와 그림:** 장보기 바구니 · 외식·배달 포크와 숟가락 · 카페·간식(기본 분류) 테이크아웃 컵 · 생활용품 택배 상자 · 교통·차량 자동차 · 병원·약 캡슐 · 쇼핑·의류 쇼핑백 · 경조사·선물 선물 상자 · 여행·숙박 비행기 · 문화·여가 티켓 · 이체·송금 주고받는 화살표(`kind-transfer`) · 주거·관리비 집 · 육아 젖병 · 반려동물 발바닥 · 기타 점 셋 · 그 밖의 이름 꼬리표 · 분류 없음 영수증 · 개인 용돈 지갑(사람 색 `a`/`b`).
- **색:** 분류마다 한 가지 중간 밝기 색(`lib/categories.ts`)을 두 테마에서 같이 씁니다. 아이콘 옆에는 늘 분류 이름이 있어서 색만으로 뜻을 전하지 않습니다.
- **꽉 채운 원:** `bg`를 주면 그 색으로 원을 꽉 채웁니다(지갑 카드 상세의 버킷 색 원). 이때 그림 색은 `ink`로 정합니다.
- 가계부 "이번 달 기록" 타일도 같은 그림 묶음을 씁니다(`trend` · `flame` · `receipt` · `piggy`, [StatTiles](../StatTiles/README.md)).
- 새 분류 그림을 더할 때는 같은 굵기(실루엣이 원의 60% 안팎)와 흰 디테일 한두 개를 지키고, 32px에서도 읽히는지 봅니다.
