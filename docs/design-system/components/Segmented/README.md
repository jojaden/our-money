# Segmented

둘에서 넷 사이의 선택지 중 하나를 고르는 컨트롤로, `well` 트랙 위에 흰 썸이 떠서 움직입니다.

## 구성
- **트랙:** `well` 바탕, `radius-small`, 안쪽 여백 3px입니다.
- **칸:** 36px 높이, 14.5px/600입니다. 고른 칸은 `text`, 나머지는 `muted`입니다.
- **썸:** `surface` 바탕, 모서리 9px, `shadow-raise`입니다. 420ms 동안 drawer 곡선으로 미끄러집니다.

## 쓰는 쪽이 줄 것
- 선택지 이름(짧게), 고른 값

## 하지 말 것
- 선택지를 다섯 개 넘게 두지 않습니다. 그때는 칩을 씁니다.
- 썸을 노랑으로 채우지 않습니다.
