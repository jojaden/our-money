# Suggest

입력칸에 글자를 치면 지난 기록 중 많이·최근에 쓴 것을 입력칸 바로 아래 칩 한 줄로 보여 주는 입력 추천입니다(`components/Suggest.tsx`, 고르는 규칙은 `lib/suggest.ts`).

## 구성
- **줄:** 입력칸 아래 8px, 칩 사이 6px. 넘치면 가로로 넘기고 스크롤바는 숨깁니다. 최대 5개(바로 쓰기 막대는 4개).
- **칩:** `suggest-h`(34px) 높이, `radius-chip`, `surface` 바탕에 1px `border` 안쪽 링, `text` 글자 14px/600. 고르는 칩(Chip)과 헷갈리지 않게 바탕을 채우지 않습니다. 긴 글은 칩 폭 75%에서 말줄임.
- **보이는 때:** 감싼 입력칸(또는 칩)에 초점이 있고, 친 글자에 맞는 추천이 있을 때만. 고른 칩은 다시 보이지 않습니다. 고르면 지난 값까지 채우는 칸(일정 제목·지출 메모·플랜 이름)은 끝까지 친 글과 같은 칩도 맨 앞에 남겨 눌러 채울 수 있게 합니다.
- **바로 쓰기 막대(달력):** 추천이 뜨면 막대가 `suggest-h` + 8px 만큼 높아집니다(`:has(.suggest)`).

## 고르는 규칙
- 한글은 자모로 풀어 앞에서부터 비교합니다 — 조합 중인 글자("관ㄹ")로도, 겹받침이 생긴 순간("값" → "갑시다")에도 맞습니다. 중간 낱말 앞("토스 송금"의 "송"), 두 글자 이상 초성("ㄱㄹㅂ" → 관리비)도 찾습니다.
- 순서: 앞에서부터 맞은 것 → 낱말 앞 → 초성, 같으면 많이 쓴 것 → 최근 것. 두 사람 기록을 모두 씁니다. 기기 안에서만 계산하고 서버에 따로 저장하지 않습니다.
- **고르면 지난 값까지:** 일정 제목은 종류·누구, 지난 일정에 있었으면 시간·알림·금액(이미 고른 값을 비우지 않음, 날짜·반복은 그대로), 지출 메모는 분류·결제수단·누구 돈(금액은 비었을 때만), 플랜 이름은 종류·금액(비었을 때만)·누구·나가는 곳·날짜·받는 곳·메모(비었을 때만). 받는 곳·플랜 메모는 글만.
- 고치는 기록(이미 있는 일정·지출·항목)에서는 이름·제목 추천을 띄우지 않습니다 — 다른 칸이 말없이 바뀌지 않게. 플랜 이름은 이번 달에 있거나 켜져 있는 플랜 항목 이름을 빼고(같은 항목이 둘 생기지 않게) 꺼 둔 항목·이번 달만 넣었던 항목을 권합니다.

## 키보드·포인터
- 칩을 눌러도 입력칸 초점이 그대로라 폰 키보드가 내려가지 않습니다(`mousedown` 기본 동작 막기 — `pointerdown` 을 막으면 WebKit 터치에서 click 이 사라집니다).
- 키보드는 Tab 으로 칩에 들어가 Enter·Space 로 고릅니다. 마우스가 있으면 올렸을 때 `well` 바탕.

## 하지 말 것
- 금액·날짜처럼 고르는 칸에는 붙이지 않습니다.
- 입력칸 위를 덮는 떠 있는 목록으로 만들지 않습니다 — 폰 키보드와 시트 아래 버튼에 가립니다.
