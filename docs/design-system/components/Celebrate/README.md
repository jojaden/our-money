# Celebrate

그달의 체크를 100% 끝낸 순간에 한 번 띄우는 축하 화면입니다. 빛이 피어나고, 볼록한 노랑 숫자가 튀어나오며 구슬이 사방으로 터지고, 해낸 일이 차례로 떠오릅니다.

## 언제 쓰나
- 체크 화면에서 그달의 이체·고정비 체크가 모두 끝난 순간, 달마다 한 번만 띄웁니다.
- 지금 달(이번 달)을 보고 있을 때만 띄웁니다. 지난 달을 넘겨 보다가 100%인 달을 만나도 띄우지 않습니다.
- 마지막 체크 원이 튀는 것을 본 다음(약 0.45초 뒤)에 띄웁니다. 다른 사람이 마지막 일을 끝냈다면 체크 화면을 처음 열 때 띄웁니다.
- 본 달은 기기에 기억해 다시 띄우지 않습니다.
- 아무 곳이나 누르거나 아래 카드를 누르면 닫히고, 키보드는 Esc로 닫습니다.
- 다음 할 일 카드는 다음 달 플랜으로 갑니다. 다음 달 플랜이 없으면 "12월 플랜 미리 만들기 · 이번 달 배분을 그대로 이어받아요", 있으면 "12월 플랜 미리 보기"입니다.
- 위쪽 막대와 캡슐까지 덮는 전체 화면입니다.

## 타임라인

| 시각 | 일어나는 일 |
|---|---|
| 0 | 바탕 빛(`bloom`)과 꽃잎 빛줄기가 0.7배에서 `dur-bloom`으로 피고, 가운데 흰 불씨가 반짝였다가 사라집니다(700ms). |
| 300ms | 숫자가 0.6배에서 `dur-pop`·`ease-pop`으로 튀어나오며 1.3초 동안 0→100으로 올라갑니다(4제곱 감속). 같은 순간 노랑 구슬 16개가 숫자 뒤에서 사방 120–210px로 터져 1.1초 만에 사라집니다. |
| 650ms | 제목(`moment-title`)이 12px 떠오릅니다. |
| 900ms | 해낸 일 알약("옮길 돈 12건", "고정비 6건", "저축 2건")이 150ms 간격으로 떠오릅니다. |
| 1500ms | 다음 할 일 카드가 아래에서 떠오릅니다. |
| 이후 | 빛줄기만 `dur-rays`에 한 바퀴 천천히 돕니다. |

- **진동:** 숫자가 튀는 순간 지원하는 기기(안드로이드)에서만 `navigator.vibrate?.(15)`로 짧게 울립니다. iOS 웹은 진동을 지원하지 않으니 진동에 의미를 싣지 않습니다.
- **움직임 줄이기:** 빛·구슬·등장을 모두 멈추고 100과 모든 글을 바로 보여 줍니다.

## 구성
- **바탕:** `glow` → `accent-soft` → `lilac` 원형 그라데이션 위에 흰 `bloom`과 흐릿한 꽃잎 빛줄기 10갈래(blur 26px)를 둡니다.
- **숫자:** `celebrate`(800)입니다. 위는 밝고 아래는 `primary-press` 쪽으로 어두운 글자 그라데이션에, 5px 진한 그림자와 넓고 옅은 그림자를 겹쳐 볼록하게 보이게 합니다.
- **구슬:** 10–18px 노랑 구(왼쪽 위 밝은 점, 아래 `primary-press`)입니다.
- **해낸 일 알약:** `surface` 75%에 `muted` 글자, 숫자는 `accent-ink`입니다.

## 하지 말 것
- 100%가 아닐 때 띄우지 않습니다.
- 같은 달에 두 번 띄우지 않습니다.
- 캐릭터, 폭죽 이모지, 색종이를 더하지 않습니다.
- 구슬을 16개보다 많이 터뜨리지 않습니다.
- 소리를 넣지 않습니다.
