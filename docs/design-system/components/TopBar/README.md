# TopBar

페이지 맨 위에 붙어 있는 막대로, 내 동전 반쪽 버튼(설정)을 둡니다. 달 넘기기는 바로 아래 큰 제목 줄(`‹ 11월 ▾ › 체크`)이 맡고, 굴려서 큰 제목 줄이 지나가면 막대 가운데로 옮겨 옵니다.

## 구성
- **내 동전 반쪽 버튼:** `topbar-btn` 정사각, `radius-control`입니다. 로그인한 사람의 `a-soft`/`b-soft` 바탕에 24px 동전 반쪽(내 쪽 반만 사람 색)을 두고, 누르면 설정으로 갑니다. `aria-label`은 "설정 (이름)"입니다.
- **가운데:** 비워 둡니다. 굴려서 큰 제목 줄이 막대 밑으로 지나가면 작은 제목 `‹ 11월 체크 ›`(600 16px, 화살표 `faint` 18px)가 떠오릅니다. 가운데 글을 누르면 달 고르기, 화살표로 달을 넘깁니다. 큰 제목 줄이 보일 때는 숨기고 누를 수 없게(inert) 둡니다. 설정 화면에서는 화살표 없이 제목만 씁니다.
- **오른쪽:** 작은 제목이 가운데 오도록 동전 버튼만큼 비워 둡니다.
- **버튼 바탕:** `surface` 70%에 `shadow-raise`입니다.
- **굴릴 때:** 막대는 화면 위에 붙어 있습니다. 큰 제목이 막대 아래 선을 지나 올라가면 막대 바탕이 유리(`surface` 72% + blur 20px·saturate 180%, 아래 0.5px 선)가 됩니다. 굴릴 때마다 재지 않고 제목이 지나가는 순간에만 바꿉니다(IntersectionObserver).
- **설정 화면:** 내 동전 버튼을 2px `accent` 안쪽 링으로 눌린 상태로 둡니다.
- **큰 제목 줄:** `‹ 11월 ▾ › 체크`(`large-title`) 아래에 기간 줄(`subhead`, "10월 25일 – 11월 24일 · 21일 남음")과 결론(`finding`)을 둡니다. 다른 달을 보고 있으면 제목 옆에 회색 알약 "이번 달로"(32px)를 둡니다.
  - 화살표는 바뀌는 것(달)만 감쌉니다. 달 이름은 두 자리 폭을 잡아 1월이든 11월이든, 탭 이름이 무엇이든 화살표가 같은 자리에 있습니다.
  - 화살표는 `faint` 24px, 누르는 칸은 44px이고 왼쪽 화살표 글리프를 여백 선에 맞춥니다. "11월 ▾"를 누르면 달 고르기 시트가 열립니다.
  - 달을 넘기면 이 줄은 제자리에 있고, 달 이름만 그 방향에서 12px 밀려 들어옵니다(`dur-tab`·`ease-drawer`). 아래 내용은 28px 밀려 들어오고, 좌우로 밀 때도 아래 내용만 손가락을 따라갑니다.
- **달 고르기 시트:** 위에 해 넘기기(`‹ 2026년 ›`), 아래에 3열 열두 칸(64px, `well`)을 둡니다. 보고 있는 달은 `primary` 채움, 이번 달은 `accent` 안쪽 링과 "이번 달", 플랜을 시작한 달은 작은 점입니다. 누르면 그 달로 가고 시트가 닫힙니다. 해를 넘기면 열두 칸이 겹쳐 바뀝니다.
- **홈의 따뜻한 띠:** 홈에서는 막대 뒤에 `warm-100` → `warm-50` → `ground` 띠를 깔고, 그 아래 `large-title`과 기간 줄을 둡니다. 다른 페이지는 `ground` 위에 바로 놓습니다.

## 쓰는 쪽이 줄 것
- 로그인한 사람(a / b), 보고 있는 달, 남은 날 수

## 하지 말 것
- 큰 제목 줄이 보일 때 막대에 달 이름이나 화살표를 함께 보이지 않습니다(같은 것이 두 번).
- 화살표를 달 이름에서 떼어 막대 끝으로 보내지 않습니다. 누르는 것과 바뀌는 것이 멀어집니다.
- 검색이나 포인트처럼 이 앱에 없는 것을 막대에 두지 않습니다.
- 따뜻한 띠를 홈 말고 다른 페이지에 깔지 않습니다.
