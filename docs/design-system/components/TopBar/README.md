# TopBar

페이지 맨 위에 붙어 있는 막대로, 내 동전 반쪽 버튼(설정)과 달 넘기기 화살표를 한 줄에 둡니다. 달 이름은 바로 아래 큰 제목과 기간 줄이 맡습니다.

## 구성
- **내 동전 반쪽 버튼:** `topbar-btn` 정사각, `radius-control`입니다. 로그인한 사람의 `a-soft`/`b-soft` 바탕에 24px 동전 반쪽(내 쪽 반만 사람 색)을 두고, 누르면 설정으로 갑니다. `aria-label`은 "설정 (이름)"입니다.
- **가운데:** 비워 둡니다. 굴려서 큰 제목이 막대 밑으로 지나가면 작은 제목("11월 체크", 600 16px)이 떠오릅니다.
- **화살표:** 지난달·다음 달, 둥근 사각 버튼 둘입니다. 설정 화면에서는 없습니다.
- **버튼 바탕:** `surface` 70%에 `shadow-raise`입니다.
- **굴릴 때:** 막대는 화면 위에 붙어 있습니다. 큰 제목이 막대 아래 선을 지나 올라가면 막대 바탕이 유리(`surface` 72% + blur 20px·saturate 180%, 아래 0.5px 선)가 됩니다. 굴릴 때마다 재지 않고 제목이 지나가는 순간에만 바꿉니다(IntersectionObserver).
- **설정 화면:** 내 동전 버튼을 2px `accent` 안쪽 링으로 눌린 상태로 둡니다.
- **큰 제목 줄:** `large-title` 아래에 기간 줄(`subhead`, "10월 25일 – 11월 24일 · 21일 남음")과 결론(`finding`)을 둡니다. 다른 달을 보고 있으면 제목 옆에 회색 알약 "이번 달로"(32px)를 둡니다.
- **홈의 따뜻한 띠:** 홈에서는 막대 뒤에 `warm-100` → `warm-50` → `ground` 띠를 깔고, 그 아래 `large-title`과 기간 줄을 둡니다. 다른 페이지는 `ground` 위에 바로 놓습니다.

## 쓰는 쪽이 줄 것
- 로그인한 사람(a / b), 보고 있는 달, 남은 날 수

## 하지 말 것
- 달 이름을 막대에 다시 쓰지 않습니다(큰 제목과 겹침). 달 고르기 시트도 두지 않습니다. 달은 화살표·좌우로 밀기·"이번 달로"로 옮깁니다.
- 검색이나 포인트처럼 이 앱에 없는 것을 막대에 두지 않습니다.
- 따뜻한 띠를 홈 말고 다른 페이지에 깔지 않습니다.
