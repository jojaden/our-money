# TopBar

페이지 맨 위에 붙어 있는 막대로, 왼쪽 위 끝에 보고 있는 달("11월"), 오른쪽에 종(알림 모음)과 톱니(설정)를 둡니다. 달 이름을 막대로 올려 따로 큰 제목 줄을 두지 않으므로, 그만큼 카드와 달력 칸이 위로 올라옵니다.

## 구성
- **오른쪽 종·톱니:** `topbar-btn` 정사각 둘(`radius-control`, 사이 8px)입니다. 종(`Bell`)은 알림 모음, 톱니(`Settings`)는 설정입니다.
  - 앱이 켜져 있을 때 상대가 공동 일정을 더하면(실시간) 토스트 "새 공동 일정 · 장보기 같이 가기 (예진)"로도 알립니다(`JointEventWatch`, 2분 안에 만든 것만). 앱이 꺼져 있을 때의 폰 푸시는 아직 없습니다.
  - 종의 새 알림 수는 오른쪽 위 18px 빨간 알약(`negative`, 흰 글자, 바탕색 2px 테두리)이고 나타날 때 `dur-pop`·`ease-pop`으로 한 번 튑니다. 숫자는 이 기기에서 종을 마지막으로 연 뒤 새로 생긴 알림 수입니다.
  - 알림 모음 시트는 "지난달 마무리"(새 달이 됐는데 마감하지 않은 지난달, 오른쪽 "마감하기") → "새 공동 일정"(상대가 7일 안에 새로 더한 공동 일정·할 일·D-day — "예진 추가 · 일정 · 11월 18일 (수)", 누르면 달력. 내가 더한 것·개인 일정·고친 것은 아님) → "기간 동안 고정"(알림 모음에 고정한 할 일) → "지난 것" → "잘 나갔나요?"(날짜가 지난 자동이체·카드 자동결제, 오른쪽 "나갔어요") → "확인할 지출"(결제 알림으로 적어 확인할 칸이 남은 지출, 누르면 가계부) → "오늘·곧"(3일 안, 할 일은 미리 알림과 3일 중 긴 쪽) → "다가오는 날"(3일 안의 월급날, 미리 알림을 켠 일정·D-day) 순서입니다. 체크할 것은 그 자리에서 체크하고, 다가오는 날을 누르면 그 화면으로 갑니다.
- **왼쪽(달 화면 — 홈·플랜·체크·가계부·달력·모든 기록):** 달 이름 "11월"(700 26px/32px `font-display`, 누르는 칸 `topbar-btn`)을 왼쪽 여백 선에 글리프를 맞춰 둡니다. 누르면 달 고르기 시트가 열립니다. 다른 달을 보면 옆에 회색 알약 "이번 달로"(32px), 예시 데이터일 때는 그 뒤에 "예시 데이터" 알약을 둡니다. 체크·가계부·플랜·달력 이름은 반복하지 않고, 화면 읽기용 h1(페이지 머리 안, 보이지 않음)에 "11월 체크"처럼 남깁니다.
  - **넘기기:** 폰·태블릿은 좌우로 밀어 넘깁니다. 화살표 `‹ ›`(`faint` 22px, 누르는 칸 32×44px)는 마우스처럼 정밀한 포인터(`hover: hover and pointer: fine`)에서만 달 이름 양옆에 보입니다(Android `adaptive`: 포인터 정밀도에 맞춘 조작).
  - **달 이름 굴리기:** 달이 바뀌면 옛 이름은 넘긴 쪽으로 빠지고 새 이름이 반대쪽에서 들어옵니다 — 다음 달은 아래에서 위로, 지난달은 위에서 아래로(60%, `dur-swap`·`ease-out`, 같은 칸에 겹쳐 잘라 냄). 막대 자체는 움직이지 않습니다.
- **왼쪽·가운데(달이 없는 화면 — 설정·모아 보기):** 왼쪽은 오른쪽 두 버튼만큼 비우고(예시 데이터 알약만), 큰 제목이 막대 밑으로 지나가면 가운데에 그 제목이 작게(600 16px) 떠오릅니다.
- **버튼:** 종·톱니는 상자·그림자 없이 아이콘만 둡니다(24px, `text`). 누르는 자리는 `topbar-btn`(44px) 그대로이고, 오른쪽 끝은 아이콘이 가장자리 여백에 맞도록 10px 당깁니다. 종의 새 알림 배지는 아이콘 어깨에 붙입니다.
- **높이:** 버튼(`topbar-btn`) 위아래 6px에 위 안전 영역만 더합니다(폰 56px + 상태 막대). 막대 안에는 버튼보다 큰 것을 두지 않습니다.
- **굴릴 때:** 막대는 화면 위에 붙어 있습니다. 페이지 머리(설정·모아 보기는 큰 제목)가 막대 아래 선을 지나 올라가면 막대 바탕이 유리(`surface` 72% + blur 20px·saturate 180%)가 됩니다. 유리는 선 없이 막대 밑으로 16px 더 내려와 그 16px 동안 옅어집니다(유리가 나타나고 사라지는 것은 투명도만, `dur-press`). 굴릴 때마다 재지 않고 제목이 지나가는 순간에만 바꿉니다(IntersectionObserver).
- **설정 화면:** 톱니 아이콘을 `accent-ink`의 굵은 선(2.4)으로 바꿔 지금 화면임을 알립니다.
- **데스크톱:** 종과 톱니는 레일 아래(종이 톱니 위)로 옮기고 막대에서는 뺍니다.
- **페이지 머리(달 화면):** 막대 바로 아래에 기간 줄(`subhead`, "10월 25일 – 11월 24일 · 21일 남음")만 둡니다(달력은 1일~말일을 달력이 보여 주므로 기간 줄 대신 요약 줄). 결론 문장은 두지 않고 첫 카드가 말합니다(홈은 맨 위 알림 카드, README "글자").
  - **달 넘기기 모션:** 막대·머리·달력 요일 줄은 제자리에 있고 그 아래 내용(달력은 날짜 칸과 모아 보기)만 움직입니다. 지금 내용이 넘기는 쪽으로 빠지며 옅어지고(최대 120px, `dur-swap`의 절반, ease-in) 새 내용이 반대쪽에서 밀려 들어옵니다(`dur-swap`·`ease-out`). `transform`·`opacity`만 바꿉니다. 손가락으로 끌던 중이면 끈 자리에서 이어서 빠집니다. 화면 전체를 깜빡이며 다시 그리지 않습니다. 탭(화면) 사이 이동은 따로 정한 페이지 전환을 그대로 씁니다.
- **달 고르기 시트:** 위에 해 넘기기(`‹ 2026년 ›`), 아래에 3열 열두 칸(64px, `well`)을 둡니다. 보고 있는 달은 `primary` 채움, 이번 달은 `accent` 안쪽 링과 "이번 달", 플랜을 시작한 달은 작은 점입니다. 누르면 그 달로 가고 시트가 닫힙니다. 해를 넘기면 열두 칸이 겹쳐 바뀝니다.
  - 달력에서는 맨 위에 세그먼트 [달 | 기간]을 둡니다. 기간은 TextTabs(이번 주 · 11월 · 9월–11월 · 2026년 · 직접)와 고른 기간 한 줄, "직접"이면 작은 달력(시작·끝 날 `primary`, 사이는 `accent-soft` 띠)이고, 아래 "모아 보기" 버튼을 누르면 달력 자리가 모아 보기로 바뀝니다.
- **모아 보기 머리:** 페이지 머리 자리에 "‹ 달력"(`accent-ink` 17px, 누르는 칸 44px), 그 아래 기간 제목(28px, 누르면 기간 바꾸기), 기간 줄("모아 보기 · 30일")을 둡니다. 달 넘기기와 좌우로 밀기는 없고, 막대 왼쪽에 달 이름도 없습니다. 들어갈 때는 오른쪽에서, 돌아올 때는 왼쪽에서 28px 밀려 들어옵니다(`dur-tab`·`ease-drawer`). 돌아가기는 브라우저 기록을 따릅니다.
- **홈의 따뜻한 띠:** 홈에서는 막대 뒤에 `warm-100` → `warm-50` → `ground` 띠를 깔고, 그 아래 `large-title`과 기간 줄을 둡니다. 다른 페이지는 `ground` 위에 바로 놓습니다.

## 하지 말 것
- 달 이름을 막대 아래에 큰 제목으로 다시 두지 않습니다(같은 것이 두 번, 카드가 그만큼 내려감).
- 폰에서 화살표를 두지 않습니다. 좌우로 밀기가 있고, 화살표는 왼쪽 위 공간만 차지합니다.
- 달을 넘길 때 막대·머리까지 함께 깜빡이거나 밀지 않습니다. 바뀌는 것(달 이름, 아래 내용)만 움직입니다.
- 달 이름 옆에 ▾ 같은 펼침 표시를 붙이지 않습니다. 제목을 누르면 고르기가 열리는 것은 따로 알리지 않아도 압니다.
- 검색이나 포인트처럼 이 앱에 없는 것을 막대에 두지 않습니다.
- 따뜻한 띠를 홈 말고 다른 페이지에 깔지 않습니다.
- 유리 아래에 선이나 그림자 줄을 긋지 않습니다. 끝이 딱 끊기면 막대가 화면을 가르는 벽처럼 보입니다.
