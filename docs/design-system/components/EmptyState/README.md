# EmptyState — 비었을 때·불러오는 동안·실패했을 때

목록이나 카드가 비었을 때 **무엇이 비었는지와 다음에 할 일**을, 목록을 받지 못했을 때 **다시 시도**를 보여 줍니다. 불러오는 동안은 `SkeletonRows` 가 실제 줄 모양 자리를 둡니다. Astryx `EmptyState`·`Skeleton`·`Banner` 지침을 이 앱 말투와 토큰으로 옮겼습니다(`README.md` › "Astryx 참고").

## 언제 쓰나
| 상황 | 쓰는 것 | 예 |
|---|---|---|
| 비었고 다음 행동이 있음 | `EmptyState` + 버튼 하나 | 이번 달 기록 없음 → "지출 기록하기", 거른 결과 0건 → "거르기 지우기", 플랜 묶음 빔 → "고정비 더하기" |
| 비었고 무엇이 모이는지 알려 주면 됨 | `EmptyState` (버튼 없음) | 종 "지금 챙길 것이 없어요", 달력 모아 보기, 변경 이력 |
| 다 끝나서 비었음 | 한 줄 `.empty` 그대로 | "남은 이체·납부가 없어요", "이번 달에 결제할 카드값이 없어요" |
| 목록을 받지 못함 | `EmptyState error` + "다시 시도" | 변경 이력 "이력을 불러오지 못했어요" |
| 받는 중(시트·목록 안) | `SkeletonRows` | 변경 이력 |
| 데이터가 있는데 새로 불러오지 못함 | 토스트 자리에 남는 알림(`Toasts` 의 `.toast.stale`) | "최신 내용을 불러오지 못했어요 · 다시 시도" |

앱을 처음 열 때의 기다림은 `Loading`, 플랜을 시작하지 않은 달처럼 화면 전체가 빈 것은 각 화면의 시작 카드가 맡습니다.

## 구성
- 바탕·모서리·안쪽 여백은 `.empty` 와 같습니다(`raised`, `radius-inner`, 14px 16px). 카드 안에 놓는 작은(compact) 모양 하나만 있습니다.
- **제목:** `text` 600 15px/21px. 무엇이 비었는지 구체적으로("이번 달 기록이 아직 없어요"). "데이터 없음", "No data" 는 쓰지 않습니다.
- **설명(선택):** `muted` 400 14px/20px. 왜 비었는지, 무엇이 여기에 모이는지 한 줄.
- **버튼(선택):** `btn secondary sm` 하나, 제목 아래 12px. 하는 일 그대로("지출 기록하기"). + 그림은 두지 않습니다.
- **실패(`error`):** 바탕 `pill-negative-bg`, 글 `pill-negative-ink`, `role="alert"`. 버튼은 늘 "다시 시도". 받은 줄이 있으면(더 보기 실패) 그 줄은 두고 아래에 "더 불러오지 못했어요".
- **줄 모양 자리(`SkeletonRows`):** 실제 줄처럼 36px 동그라미 + 두 줄(58%·36% 폭, `well`), 기본 3줄. `role="status"` 와 무엇을 받는지 이름("변경 이력을 불러오는 중").

## 움직임
- 줄 모양 자리는 `dur-breathe`·`ease-breathe` 로 숨 쉬듯 옅어졌다(45%) 짙어집니다. 줄마다 160ms 씩 늦게 시작합니다. `opacity` 만 움직입니다.
- 움직임 줄이기 설정이면 멈춥니다.
- 빈 화면과 실패 상자는 스스로 움직이지 않습니다(카드 안이면 `Morph` 가 높이를 맞춥니다).

## 하지 말 것
- 실패를 빈 화면처럼 쓰지 않습니다("아직 바뀐 기록이 없어요"가 아니라 "불러오지 못했어요").
- 실패를 저절로 사라지는 토스트로만 알리지 않습니다.
- 버튼을 둘 넘게 두지 않습니다. 다음 행동이 없으면 버튼도 없습니다.
- 크기를 아는 자리에 빙글빙글 도는 표시를 쓰지 않습니다(줄 모양 자리를 씁니다). 줄 모양 자리와 도는 표시를 같이 쓰지 않습니다.

## 앱
- `components/ui.tsx` `EmptyState`·`SkeletonRows`, 남는 알림은 같은 파일 `Toasts`. 스타일은 `app/controls.css` "빈 화면"·`app/shell.css` `.toast`.
