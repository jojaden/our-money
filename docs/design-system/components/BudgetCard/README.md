# BudgetCard

예산 하나의 남은 돈을 답 숫자 하나와 게이지로 보여 주는 카드입니다. 홈 첫 카드(공동 생활비)는 Alan Today 화면처럼 굵은 반원 호 아래로 하늘색이 흰 바탕에 스며드는 **큰 카드**이고, 내 용돈은 270° 게이지를 오른쪽에 둔 **작은 카드**입니다.

## 큰 카드 (홈 첫 카드)
- **하늘 머리:** `sky-100` → `glow` 세로 그라데이션 위에 카드 이름(`headline`)과 이동 링크(`faint`, ›)를 둡니다.
- **반원 호:**
  - 지름 248px(폭 300px까지 늘고 줄어듦), 선 22px, 둥근 끝입니다.
  - 왼쪽 끝이 0, 오른쪽 끝이 예산 100%입니다.
  - 재질은 README "게이지와 막대"의 빛을 머금은 튜브입니다. 채운 호는 옅은 버킷 색에서 진한 끝으로 번지고, 굵기 방향 입체를 덧씌우고, 둘레에 같은 색 빛이 돕니다.
  - 빈자리는 같은 입체의 흰 라일락 튜브입니다.
- **끝 점:** 채운 호 끝에 테두리 없는 흰 점(지름 13px)과 옅은 그림자를 둡니다.
- **오늘 이정표:** 오늘까지 예상 속도 자리의 호 위에 흰 점(`버킷 글자색` 2px 테두리)을 찍습니다. 호 안쪽에는 "오늘"을 호를 따라 휘게 씁니다(`caption`, 버킷 글자색). Alan Walk 게이지의 "2 500" 이정표와 같은 방식입니다.
- **호 가운데:** 사용 %(Alan Sans 800, 44px, "%"는 0.5em `faint`)와 "사용"(`caption`)입니다.
- **바탕:** `sky-100` → `glow`(55%) → `surface` 세로 그라데이션이 호의 다리 아래에서 흰 바탕으로 이어집니다. 머리와 아래를 가르는 선이나 곡선은 두지 않습니다.
- **아래 칸:**
  - 가운데 정렬입니다.
  - 패널 안 순서:
    1. "남은 돈"
    2. `figure` 금액
    3. "1,400,000원 중 390,000원 썼어요"
    4. 속도 알약
    5. 하루 금액
    6. 결제수단 나눔(토스 소비 분석처럼): 비율 막대 한 줄(8px, 칸 사이 2px, 끝 4px 둥글게, 처음 그릴 때 왼쪽에서 `dur-ring`·`ease-out`으로 펼침)과 그 아래 목록(점 10px · 이름 + `faint` % · 금액, 줄 사이 `rule`). 0원인 수단은 빼고, 순서와 색은 카드(`kind-card`)·현금(`kind-cash`)·계좌이체(`kind-transfer`)로 고정합니다. %는 합이 100이 되게 반올림하고 0이 되면 "1% 미만"으로 씁니다. 넓은 화면에서는 440px까지만 넓힙니다.

## 속도 알약과 하루 금액
- 예상보다 덜 썼으면 `pill-positive-*`에 `TrendingDown` 아이콘을 붙여 "예상보다 106,774원 덜 썼어요"라고 씁니다.
- 예상보다 더 썼으면 `pill-warning-*`에 `TrendingUp` 아이콘을 붙여 "예상보다 21,226원 더 썼어요"라고 씁니다. 꾸짖지 않고 사실만 말합니다.
- 예산을 넘었으면 `pill-negative-*`에 `CircleAlert` 아이콘을 붙여 "예산을 120,000원 넘었어요"라고 씁니다.
- 하루 금액은 큰 카드에서 "남은 21일, 하루 48,095원씩 쓸 수 있어요", 작은 카드에서 "하루 11,700원"입니다. 다 썼으면 "이번 달 예산을 다 썼어요"라고 씁니다.

## 버킷별 색
| 버킷 | 호·끝 점 (`--c`) | 이정표 글자 (`--ink`) | 머리 |
|---|---|---|---|
| 공동 생활비 | `g-living` | `accent-ink` | 하늘(`sky-100` → `glow`) |
| 용돈 | `g-allowance` | `warning` | 작은 카드라 머리 없음 |
| 예산 초과(어느 버킷이든) | `negative` | `pill-negative-ink` | 그대로 |

예산을 넘으면 호를 100%에서 멈추고 호·끝 점을 통째로 `negative`로 바꿉니다. "남은 돈" 이름표는 "예산 초과"가 되고 금액은 넘은 만큼을 `negative`로 씁니다. 두 번째 바퀴는 그리지 않습니다.

## 움직임
- **앱을 열고 처음 볼 때:** 0에서 쓴 돈까지 `dur-ring`·`ease-out`으로 그립니다. 채운 호, 끝 점, %, 남은 돈 숫자는 한 값으로 같은 박자에 움직입니다. 그래서 숫자와 끝 점은 CSS 전환 대신 같은 곡선으로 프레임마다 계산하고, React 상태를 거치지 않고 그 요소만 바꿉니다.
- **값이 바뀔 때:** 지금 보이는 값에서 새 값으로 `dur-value`·`ease-value`로 이어 갑니다. 움직이는 중에 또 바뀌면 그 자리에서 다시 출발합니다.
- **탭을 다시 열거나 달을 넘길 때:** 버킷마다 마지막으로 보인 값을 기억합니다. 탭을 다시 열면 그대로 두고, 달을 넘기면 지난 달 값에서 새 달 값으로 이어 갑니다(예: 10월 94% → 11월 28%). 0부터 다시 그리지 않습니다.
- 속도 알약과 글 줄은 바로 바뀝니다.
- 움직임 줄이기 설정이면 끝 값을 바로 보여 줍니다.

## 할 일 진행
- 홈의 "이번 달 할 일" 카드는 작은 카드와 같은 270° 튜브(80px, `accent`)에 가운데 %만 둡니다. 끝 점은 있고 이정표는 없습니다.
- 체크 화면 머리의 진행률도 같은 `TaskGauge`를 씁니다. 체크 추가·해제 모두 호·끝 점·%가 `dur-value`·`ease-value`로 이어지고, 연속 입력은 현재 보이는 값에서 다시 출발합니다. 구현을 바꿀 때는 [공통 움직임 유지와 회귀 검증](../../README.md#움직임-유지와-회귀-검증)을 따릅니다.

## 접근성
- 게이지 SVG는 `role="img"`이고, 이름은 "예산의 28% 사용, 오늘까지 예상 35%"입니다.
- 가운데 % 글자는 `aria-hidden`입니다.

## 하지 말 것
- 한 화면에 큰 카드를 둘 두지 않습니다. 큰 카드는 홈 첫 카드 하나뿐이고, 나머지 예산은 작은 카드입니다.
- 카드 하나에 답 숫자를 둘 이상 두지 않습니다.
- 호 색을 버킷과 다르게 칠하지 않습니다. 길이 그라데이션은 같은 버킷 색의 옅은 → 진한 번짐만 씁니다.
- 채운 호에 진한 테두리나 가운데 흰 띠를 겹치지 않습니다(예전 세 겹 튜브가 두 줄 띠처럼 보였음).
- 결제수단을 칸 타일로 나누지 않습니다. 세 칸이 같은 무게로 보여 비중이 안 읽히고, 0원 칸이 자리를 차지합니다.
- 카드에 `border`를 두지 않습니다. 가장자리는 `shadow-card` 안의 1px 링이 냅니다.
