# BudgetCard

예산 하나의 남은 돈을 **큰 숫자 하나 + 예산 대비 가로 막대**로 보여 주는 카드입니다(README "숫자와 막대": 이번 달 지출 → 숫자 + 예산 대비 막대). 홈 첫 카드(공동 생활비)가 **큰 카드**, 내 용돈이 **작은 카드**이고 둘은 같은 모양에 숫자 크기만 다릅니다.

## 순서 (위에서 아래로, 왼쪽 정렬)
1. 머리: 카드 이름(`headline`)과 이동 링크(`faint`, ›)
2. 이름표 "남은 돈"(`faint`) — 넘으면 "예산 초과"
3. **금액**: 큰 카드 `display` 36px, 작은 카드 28px. "원"은 0.62em `faint`. 넘으면 넘은 만큼을 `negative`로
4. **막대**(`Meter`): 높이 10px, 트랙 `well`, 채움 `accent`(넘치면 `negative`). 오늘까지 써도 되는 자리에 진한 눈금(2px `text`, 위아래 4px). 큰 카드만 눈금 위에 "오늘"(`caption`, `faint`)
5. 설명: "1,400,000원 중 595,100원 썼어요 · 43%"(`muted`) — %는 여기에만
6. 속도 알약과 하루 금액(한 줄, 좁으면 줄바꿈)
7. 결제수단: 큰 카드는 목록(점 · 이름 + `faint` % · 금액, 줄 사이 `rule`), 작은 카드는 `meta`·`faint` 한 줄("카드 120,000원 · 현금 34,300원"). 0원인 수단은 빼고 순서와 점 색은 카드(`kind-card`)·현금(`kind-cash`)·계좌이체(`kind-transfer`)로 고정합니다. 바로 위 예산 막대와 헷갈리지 않게 **비율 막대는 그리지 않습니다** — 목록에 %와 금액이 이미 있습니다.

## 속도 알약과 하루 금액
- 예상보다 덜 썼으면 `pill-positive-*`에 `TrendingDown` 아이콘을 붙여 "예상보다 106,774원 덜 썼어요"라고 씁니다.
- 예상보다 더 썼으면 `pill-warning-*`에 `TrendingUp` 아이콘을 붙여 "예상보다 21,226원 더 썼어요"라고 씁니다. 꾸짖지 않고 사실만 말합니다.
- 예산을 넘었으면 `pill-negative-*`에 `CircleAlert` 아이콘을 붙여 "예산을 120,000원 넘었어요"라고 씁니다.
- 하루 금액은 큰 카드에서 "남은 21일, 하루 48,095원씩 쓸 수 있어요", 작은 카드에서 "하루 11,700원"입니다. 다 썼으면 "이번 달 예산을 다 썼어요"라고 씁니다.

## 색
- 버킷과 상관없이 막대 채움은 `accent` 하나입니다(같은 뜻 = 같은 색). 넘치면 `negative` 하나로 바뀝니다.
- 카드 바탕은 다른 카드와 같은 `surface-card`입니다. 그라데이션 머리를 깔지 않습니다.

## 움직임
- **앱을 열고 처음 볼 때:** 0에서 쓴 돈까지 `dur-ring`·`ease-out`으로 채웁니다. 막대와 남은 돈 숫자는 한 값으로 같은 박자에 움직입니다(`useTween`이 React 상태를 거치지 않고 그 요소만 바꿈). 막대는 `translateX`만 바꿔 레이아웃 없이 움직입니다.
- **값이 바뀔 때:** 지금 보이는 값에서 새 값으로 `dur-value`·`ease-value`로 이어 갑니다. 움직이는 중에 또 바뀌면 그 자리에서 다시 출발합니다.
- **탭을 다시 열거나 달을 넘길 때:** 버킷마다 마지막으로 보인 값을 기억해 0부터 다시 그리지 않습니다.
- 움직임 줄이기 설정이면 끝 값을 바로 보여 줍니다.

## 할 일 진행
- 홈 "이번 달 할 일" 카드와 체크 화면 머리는 **숫자 "9 / 20 완료"를 먼저** 쓰고 그 아래 같은 막대(`TaskMeter`, 8px, 이정표 없음)를 둡니다. 체크 추가·해제 모두 `dur-value`·`ease-value`로 이어 갑니다. 구현을 바꿀 때는 [공통 움직임 유지와 회귀 검증](../../README.md#움직임-유지와-회귀-검증)을 따릅니다.

## 쓰는 쪽이 줄 것
- 버킷, 예산, 쓴 돈, 오늘까지 예상 금액, 남은 날 수, 결제 수단별 합계

## 접근성
- 막대는 `role="img"`이고, 이름은 "예산의 28% 사용, 오늘까지 예상 35%"입니다. 움직이는 숫자는 `aria-hidden`이고 끝 값을 `sr-only`로 읽어 줍니다.

## 하지 말 것
- 반원·링 게이지로 되돌리지 않습니다. 작은 자리에서 숫자를 밀어냅니다.
- 카드 하나에 답 숫자를 둘 이상 두지 않습니다. %를 금액보다 크게 쓰지 않습니다.
- 막대를 버킷마다 다른 색으로 칠하거나 그라데이션으로 번지게 하지 않습니다.
- 결제수단을 칸 타일이나 또 하나의 막대로 나누지 않습니다.
- 카드에 `border`나 링을 두지 않습니다. 가장자리는 `surface-card` 그라데이션과 `shadow-card`로 바탕에 스며들게 냅니다.
