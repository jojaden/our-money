# BudgetCard

예산 하나의 남은 돈을 답 숫자 하나와 게이지로 보여 주는 카드입니다. 홈 첫 카드(공동 생활비)는 Alan Today 화면처럼 굵은 반원 호에 곡선 패널을 겹친 **큰 카드**이고, 내 용돈은 270° 게이지를 오른쪽에 둔 **작은 카드**입니다.

## 큰 카드 (홈 첫 카드)
- **하늘 머리:** `sky-100` → `glow` 세로 그라데이션 위에 카드 이름(`headline`)과 이동 링크(`faint`, ›)를 둡니다.
- **반원 호:**
  - 지름 248px(폭 300px까지 늘고 줄어듦), 선 22px, 둥근 끝입니다.
  - 왼쪽 끝이 0, 오른쪽 끝이 예산 100%입니다.
  - 무지개 게이지와 같은 튜브(테두리·몸통·가운데 빛 세 겹)입니다.
  - 빈자리는 옅은 라일락빛 흰 튜브, 채운 호는 버킷 색 튜브입니다.
- **끝 점:** 채운 호 끝에 흰 점(지름 16px, 버킷 색 3.5px 테두리, 같은 색 옅은 빛)을 둡니다.
- **오늘 이정표:** 오늘까지 예상 속도 자리의 호 위에 흰 점(`버킷 글자색` 2px 테두리)을 찍습니다. 호 안쪽에는 "오늘"을 호를 따라 휘게 씁니다(`caption`, 버킷 글자색). Alan Walk 게이지의 "2 500" 이정표와 같은 방식입니다.
- **호 가운데:** 사용 %(Alan Sans 800, 44px, "%"는 0.5em `faint`)와 "사용"(`caption`)입니다.
- **곡선 패널:**
  - 흰 패널이 볼록한 곡선(가로 50% / 세로 30px 모서리)으로 호의 두 다리 바로 아래까지 올라옵니다.
  - 패널 안은 가운데 정렬입니다.
  - 패널 안 순서:
    1. "남은 돈"
    2. `figure` 금액
    3. "1,400,000원 중 390,000원 썼어요"
    4. 속도 알약
    5. 하루 금액
    6. 결제 수단 타일 세 칸(`well`, `radius-small`)

## 작은 카드 (내 용돈 등)
- 왼쪽에 "남은 돈", `figure-compact` 금액, 사용 줄(`text-wrap: balance`)을 둡니다.
- 오른쪽은 96px 270° 게이지입니다.
  - 아래가 열려 있고, 선은 10px입니다. 흰 카드 위라서 빈자리 튜브를 조금 더 진하게(`lilac` 62%) 합니다.
  - 끝 점은 지름 11px, 오늘 이정표는 작은 흰 점입니다. 글자는 없습니다.
  - 가운데에 %를 씁니다.
- 아래에 속도 알약과 "하루 …원"을 한 줄에 두고, 결제 수단은 `meta`·`faint` 한 줄("카드 120,000원 · 현금 34,300원 · 계좌이체 0원")로 줄입니다.

## 속도 알약과 하루 금액
- 예상보다 덜 썼으면 `pill-positive-*`에 `TrendingDown` 아이콘을 붙여 "예상보다 106,774원 덜 썼어요"라고 씁니다.
- 예상보다 더 썼으면 `pill-warning-*`에 `TrendingUp` 아이콘을 붙여 "예상보다 21,226원 더 썼어요"라고 씁니다. 꾸짖지 않고 사실만 말합니다.
- 예산을 넘었으면 `pill-negative-*`에 `CircleAlert` 아이콘을 붙여 "예산을 120,000원 넘었어요"라고 씁니다.
- 하루 금액은 큰 카드에서 "남은 21일, 하루 48,095원씩 쓸 수 있어요", 작은 카드에서 "하루 11,700원"입니다. 다 썼으면 "이번 달 예산을 다 썼어요"라고 씁니다.

## 버킷별 색
| 버킷 | 호·끝 점 (`--c`) | 이정표 글자 (`--ink`) | 머리 |
|---|---|---|---|
| 공동 생활비 | `g-living` | `accent-ink` | 하늘(`sky-100` → `glow`) |
| 용돈 | `g-allowance` | `warning` | 작은 카드라 머리 없음 |
| 예산 초과(어느 버킷이든) | `negative` | `pill-negative-ink` | 그대로 |

예산을 넘으면 호를 100%에서 멈추고 호·끝 점을 통째로 `negative`로 바꿉니다. "남은 돈" 이름표는 "예산 초과"가 되고 금액은 넘은 만큼을 `negative`로 씁니다. 두 번째 바퀴는 그리지 않습니다.

## 움직임
- **처음 열 때:** 0에서 쓴 돈까지 `dur-ring`·`ease-out`으로 그립니다. 채운 호, 끝 점, %, 남은 돈 숫자는 한 값으로 같은 박자에 움직입니다. 그래서 숫자와 끝 점은 CSS 전환 대신 같은 곡선으로 프레임마다 계산합니다.
- **값이 바뀔 때:** 지금 보이는 값에서 새 값으로 `dur-value`·`ease-value`로 이어 갑니다. 움직이는 중에 또 바뀌면 그 자리에서 다시 출발합니다.
- 속도 알약과 글 줄은 바로 바뀝니다.
- 움직임 줄이기 설정이면 끝 값을 바로 보여 줍니다.

## 쓰는 쪽이 줄 것
- 버킷(색을 정함), 예산, 쓴 돈, 오늘까지 예상 금액, 남은 날 수, 결제 수단별 합계

## 접근성
- 게이지 SVG는 `role="img"`이고, 이름은 "예산의 28% 사용, 오늘까지 예상 35%"입니다.
- 가운데 % 글자는 `aria-hidden`입니다.

## 하지 말 것
- 한 화면에 큰 카드를 둘 두지 않습니다. 큰 카드는 홈 첫 카드 하나뿐이고, 나머지 예산은 작은 카드입니다.
- 카드 하나에 답 숫자를 둘 이상 두지 않습니다.
- 호 색을 버킷과 다르게 칠하지 않습니다. 호 길이를 따라 색이 변하는 그라데이션을 넣지 않습니다(튜브 빛만 씁니다).
- 카드에 `border`를 두지 않습니다. 가장자리는 `shadow-card` 안의 1px 링이 냅니다.
