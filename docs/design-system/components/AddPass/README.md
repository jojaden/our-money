# AddPass

카드·통장을 지갑에 넣는 시트입니다. 앱의 `AccountSheet`(새로 추가)를 대신합니다. 맨 위 카드 그림이 적는 대로 바뀌어서, 저장하기 전에 지갑에서 어떻게 보일지 바로 압니다.

## 구성
- **시트:**
  - 바탕은 `ground`, 위 모서리는 `radius-sheet`, 손잡이가 있습니다.
  - 머리 왼쪽에 "취소"(`accent-ink` 글자), 가운데에 "카드 추가" / "통장 추가"(17px/700)를 둡니다.
- **미리보기 카드:**
  - 시트 폭의 82%, 실물 카드 비율입니다. 그림 규칙은 Wallet과 같습니다.
  - 새 신용카드는 아직 쓴 돈이 없어 흰 카드이고, 통장은 `pass-dark`에 주인 색 점입니다.
  - 비어 있는 칸은 자리 글자("카드 이름", "카드사", "•••• ····")를 45%로 옅게 보여 줍니다.
- **종류(맨 위):** 처음 넣을 때 머리 바로 아래, 미리보기보다 먼저 세그먼트 "신용·체크카드 | 통장·증권 계좌"를 둡니다(지갑의 + 는 하나라 통장도 여기서 고릅니다 — 처음 쓰는 사람이 통장 넣는 곳을 못 찾지 않게). 바꾸면 미리보기 카드가 세로축으로 뒤집힙니다(`dur-pop`·`ease-drawer`). 앞면은 신용카드, 뒷면은 통장입니다.
- **하는 일 한 줄:** 종류 바로 아래 `muted` 13.5px 로, 그 종류가 앱에서 무엇에 쓰이는지 씁니다. 카드: "지출을 적을 때 어느 카드로 냈는지 고르고, 결제일이 되면 카드값을 챙겨 줘요." 통장: "월급이 들어오고 이체·카드값이 빠져나가는 계좌예요. 플랜에서 어디서 어디로 옮길지 고를 때 써요. 잔액은 관리하지 않아요."
- **묶음 입력(흰 묶음, 모서리 `radius-control`, 줄 높이 50px):**
  - 왼쪽에 이름표(`muted`, 74px), 오른쪽 정렬 값을 둡니다.
  - 첫 묶음: 이름, 카드사/은행, 끝 4자리(카드·통장 모두, 숫자 4개만 받음, 선택)
    - **이름 아래 한 줄**(`faint` 12.5px): 이 이름이 어디에 나오는지. 카드 "지출을 적을 때·카드값 목록에 이 이름으로 나와요…", 통장 "이체 목록에 "어디 → 어디"로 이 이름이 나와요. 하는 일을 이름에 넣으면 알아보기 쉬워요."
    - **이름 추천 칩**(이름이 비었을 때만): 누구 것·종류에 맞춘 흔한 이름 — 공동 통장 "공동 생활비통장 · 고정비 통장 · 비상금 통장 · 공동 적금", 개인 통장 "현빈 급여통장 · 현빈 용돈통장 · 현빈 적금", 공동 카드 "공동 신용카드 · 공동 체크카드 · 생활비 카드", 개인 카드 "현빈 카드 · 현빈 체크카드". 지갑에 이미 있는 이름은 뺍니다. 누르면 이름에 들어갑니다.
    - **끝 4자리:** 안내 글 "카드번호 끝 4자리 (선택)" / "계좌번호 끝 4자리 (선택)". 통장은 지갑 카드 아래에 "통장 •••• 4821"로 보입니다. 계좌번호 전체는 받지 않습니다 — 앱이 돈을 옮기지 않아 필요 없고, 같은 은행 통장이 여럿일 때 끝 4자리면 알아보기에 충분합니다(도움말에 이 이유를 씁니다).
  - 둘째 묶음:
    - "누구 것": 공동 / 현빈 / 예진 알약. 동전 반쪽이 붙고, 고른 것은 Chip과 같은 모양입니다.
    - 결제 계좌, 결제일: 신용카드만. 오른쪽 값과 `ChevronRight`가 있고, 누르면 고르는 시트가 열립니다.
  - 그 아래 도움말: "공동 지출을 개인 카드·통장으로 내면 정산 대상이 돼요."
- **버튼:** 맨 아래 블록 버튼 "지갑에 넣기"입니다. 이름을 적기 전에는 흐리게 막습니다.

## 지갑에 넣는 순간
- 미리보기 카드가 아래(지갑 쪽)로 420px 내려가며 70%로 작아지고 사라집니다(`dur-tab`·`ease-drawer`).
- 버튼 글은 "지갑에 넣었어요"가 되고, 지원하는 기기에서 짧게 진동합니다.
- 시트가 닫힌 뒤 지갑 묶음에서는 새 카드가 맨 아래에서 올라와 제자리에 끼어듭니다.

## 고칠 때
- 이미 있는 카드를 누르면 같은 시트를 "고치기"로 엽니다. 종류 세그먼트는 숨기고, 머리 오른쪽에 위험 버튼 "숨기기"를 둡니다.
- 숨긴 카드는 지갑 `…` → "숨긴 카드"에서 되살립니다.

## 카드사·은행 고르기와 색
- **카드사/은행 칸:** 몇 글자만 쳐도 아래에 맞는 이름이 칩으로 뜹니다(카드사 목록 / 은행·증권사 목록, 앞에서 맞는 것 먼저 6개). 칩에는 그 회사 로고(18px)가 앞에 붙고, 누르면 그 이름이 들어가며 위 미리보기 카드의 기관 표시도 그 로고로 바뀝니다. 띄어쓰기·대소문자만 다르게 쳐도 칸을 떠날 때 목록의 이름으로 맞춥니다("kb 국민 카드" → "KB국민카드"). 이름이 한 가지로 맞춰져야 카드 알림으로 카드사를 찾을 때 헷갈리지 않습니다. 목록에 없는 이름도 그대로 적을 수 있습니다.
- **색(신용카드만):** "자동"과 여덟 색 동그라미를 한 줄에 둡니다. 고르면 미리보기 카드가 바로 그 색이 됩니다. "자동"은 이번 달 쓴 버킷 색 번짐입니다(Wallet). 저장은 `accounts.color`(migrations/008)입니다.

## 앱에서
- 머리는 앱의 다른 시트와 같이 제목 왼쪽, 위험 버튼 오른쪽입니다("취소"는 손잡이·바깥 누르기·뒤로 가기로 대신합니다).
- 결제 계좌·결제일은 묶음 안의 기본 선택 상자(오른쪽 정렬)입니다. 따로 고르는 시트를 열지 않습니다.
- 결제일 "없음 (체크카드)"를 고르면 체크카드로 봅니다.
- 끝 4자리 칸은 숫자만 남기고 4자리에서 자릅니다(붙여 넣어도 숫자만).

## 쓰는 쪽이 줄 것
- 통장 목록(결제 계좌 고르기용), 사람 이름

## 하지 말 것
- 카드 번호 전체, 유효기간, CVC를 받지 않습니다. 끝 4자리는 카드 알림에서 카드를 찾는 데만 씁니다.
- 카메라로 카드 읽기를 넣지 않습니다(번호 전체를 다루게 됨).
- 카드사가 만든 카드 그림을 고르게 하지 않습니다(로고는 기관 표시와 칩에만).
