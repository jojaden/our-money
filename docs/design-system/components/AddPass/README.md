# AddPass

카드·통장을 지갑에 넣는 시트입니다. 앱의 `AccountSheet`(새로 추가)를 대신합니다. 맨 위 카드 그림이 적는 대로 바뀌어서, 저장하기 전에 지갑에서 어떻게 보일지 바로 압니다.

## 구성
- **시트:**
  - 바탕은 `ground`, 위 모서리는 `radius-sheet`, 손잡이가 있습니다.
  - 머리 왼쪽에 "취소"(`accent-ink` 글자), 가운데에 "카드 추가" / "통장 추가"(17px/700)를 둡니다.
- **미리보기 카드:**
  - 시트 폭의 82%, 실물 카드 비율입니다. 그림 규칙은 Wallet과 같습니다.
  - 새 신용카드는 아직 쓴 돈이 없어 흰 카드이고, 통장은 `pass-dark`에 주인 색 점입니다.
  - 비어 있는 칸은 자리 글자("카드 이름", "카드사", "•••• ····")를 45%로 옅게 보여 줍니다.
- **종류:** 세그먼트 "신용카드 | 통장"입니다. 바꾸면 미리보기 카드가 세로축으로 뒤집힙니다(`dur-pop`·`ease-drawer`). 앞면은 신용카드, 뒷면은 통장입니다.
- **묶음 입력(흰 묶음, 모서리 `radius-control`, 줄 높이 50px):**
  - 왼쪽에 이름표(`muted`, 74px), 오른쪽 정렬 값을 둡니다.
  - 첫 묶음: 이름, 카드사/은행, 끝 4자리(신용카드만, 숫자 4개만 받음)
  - 둘째 묶음:
    - "누구 것": 공동 / 현빈 / 예진 알약. 동전 반쪽이 붙고, 고른 것은 Chip과 같은 모양입니다.
    - 결제 계좌, 결제일: 신용카드만. 오른쪽 값과 `ChevronRight`가 있고, 누르면 고르는 시트가 열립니다.
  - 그 아래 도움말: "공동 지출을 개인 카드·통장으로 내면 정산 대상이 돼요."
- **버튼:** 맨 아래 블록 버튼 "지갑에 넣기"입니다. 이름을 적기 전에는 흐리게 막습니다.

## 지갑에 넣는 순간
- 미리보기 카드가 아래(지갑 쪽)로 420px 내려가며 70%로 작아지고 사라집니다(`dur-tab`·`ease-drawer`).
- 버튼 글은 "지갑에 넣었어요"가 되고, 지원하는 기기에서 짧게 진동합니다.
- 시트가 닫힌 뒤 지갑 묶음에서는 새 카드가 맨 아래에서 올라와 제자리에 끼어듭니다.

## 고칠 때
- 이미 있는 카드를 누르면 같은 시트를 "고치기"로 엽니다. 종류 세그먼트는 숨기고, 머리 오른쪽에 위험 버튼 "숨기기"를 둡니다.
- 숨긴 카드는 지갑 `…` → "숨긴 카드"에서 되살립니다.

## 쓰는 쪽이 줄 것
- 통장 목록(결제 계좌 고르기용), 사람 이름

## 하지 말 것
- 카드 번호 전체, 유효기간, CVC를 받지 않습니다. 끝 4자리는 카드 알림에서 카드를 찾는 데만 씁니다.
- 카메라로 카드 읽기를 넣지 않습니다(번호 전체를 다루게 됨).
- 실제 카드사 로고나 카드 그림을 고르게 하지 않습니다.
