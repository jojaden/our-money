# Calendar — 월 달력과 날짜 패널

월 달력이 기본 화면을 차지합니다. 월 전체 목록과 특정 날짜의 상세를 한 화면에 늘어놓지 않습니다. 참고 화면의 월 격자·날짜 패널·추가 흐름을 기존 앱의 색·글꼴·Sheet에 적용합니다.

## 구성

- **머리:** 월 왼쪽의 메뉴 버튼(44px)에서 `할 일·일정`과 `D-day`를 따로 엽니다. 큰 제목은 월만 표시하고, 월 화살표·달 고르기·기간 모아 보기를 유지합니다.
- **월 격자:** 카드로 감싸지 않습니다. 휴대폰·태블릿(1024px 미만)에서는 바깥 여백을 거슬러 화면 가장자리 4px(가로 안전 영역이 더 크면 그만큼)까지 넓히고, 레일이 있는 넓은 화면에서는 본문 너비를 씁니다. 모든 너비에서 7열을 넓게 사용합니다. 날짜 칸은 높이 112~148px, 일정 이름은 최대 3개와 남은 개수입니다. 긴 이름은 말줄임하고 접근성 이름과 상세에는 전체 제목을 남깁니다. 기간 일정은 걸친 날짜마다 이름을 표시합니다.
- **구분:** 일정은 입력한 사람(`created_by`)의 색으로 칠합니다. 왼쪽 2px 막대는 `a`/`b` 원색, 바탕은 같은 색을 `surface`에 32% 섞은 색, 글자는 대비를 위해 `text`입니다. 입력한 사람을 모르면 `joint` 색(24%)입니다. 날짜 패널의 일정 점도 같은 기준입니다. 오늘은 `primary` 원, 선택한 날짜는 `accent-soft`·안쪽 선입니다. 지출 금액과 월급·결제·이체의 점 표시도 유지합니다.
- **날짜 선택:** 클릭·Enter·Space로 날짜를 고르면 그날 일정·돈 일·지출을 담은 패널이 아래에서 올라옵니다. 볼 것이 없는 날은 패널을 열지 않고 고르기만 합니다. 패널 머리의 닫기는 상자 없이 아이콘만 두고, `N월 N일에 일정 추가`는 패널 맨 아래의 넓은 버튼입니다. 아래 추가 버튼의 이름이 `11월 19일에 일정 추가`처럼 고른 날짜로 바뀝니다. 패널을 연 채로 내역이 모두 지워지면 상자 없이 가운데에 아이콘·`비어 있는 날이에요`·안내 한 줄·`일정 추가` 버튼을 둡니다.
- **날짜 패널:** 애플 캘린더 목록 보기를 참고했습니다.
  - 제목은 `11월 21일 토요일`이고, 그 아래 한 줄에 `오늘·내일·3일 뒤·3일 전`과 개수를 적습니다.
  - 내용은 `일정` → `들어올 돈`(월급날) → `나갈 돈`(카드값·고정비·저축 이체) → `쓴 돈`(합계) 순으로 묶습니다. 묶음 사이는 선 대신 20px 간격입니다.
  - 일정 한 줄은 왼쪽부터 시간 칸(64px: `하루 종일`, 또는 시작·끝 시각 `오후 3:00`), 입력한 사람 색 4px 막대, 제목(16px 600)과 부가 정보(기간·누구 일정·할 일·메모), 금액·D-day 순입니다.
  - 하루 종일 일정이 먼저 오고, 나머지는 시작 시각 순입니다. 할 일은 맨 끝 동그라미로 끝내고, 끝낸 일은 제목에 줄을 긋고 막대를 흐리게 합니다. 다른 달의 회색 날짜를 고르면 그 달로 이동한 뒤 해당 날짜 패널을 엽니다.
- **추가:** 날짜 패널 맨 아래의 `N월 N일에 일정 추가`는 그 날짜를 미리 넣은 `새 일정`을 엽니다. 할 일·D-day로 바꾸기, 시간·기간·반복·누구·알림·메모는 기존 EventSheet를 사용합니다. 아래에는 `취소`·`저장`을 둡니다. 이미지 속 개인 일정·이름·장소는 예시로 복사하지 않습니다.
- **월 전체 보기:** 메뉴 패널의 세그먼트로 `할 일·일정`과 `D-day`를 바꿉니다. 기존 MonthTodo의 가계부 기간·완료 체크와 D-day의 다음 회차 계산을 유지합니다.
- **한 주 접기:** 기존 손잡이와 주 이동을 유지합니다. 접힌 주를 좌우로 넘기는 동작은 날짜 패널을 자동으로 열지 않습니다.

## 움직임·돌아오기

날짜·월 전체 목록은 공통 `Sheet`의 세로 열기/닫기와 `Morph`를 재사용합니다. 페이지 이동에 정한 짧은 가로 전환과 구분합니다. 닫히는 동안 제목·내용을 월 목록으로 바꾸지 않고 마지막 내용을 유지합니다.

패널의 `+`, 일정 고치기, 지출 고치기, 체크 화면 링크는 `afterSheet`로 패널의 기록이 닫힌 뒤 이동합니다. 일정 입력을 저장·취소하거나 뒤로 닫으면 열었던 날짜/월 목록 패널로 돌아옵니다. 날짜/월 목록 패널에서 뒤로가기·Escape·아래로 밀기·닫기 버튼을 쓰면 보던 달력으로 돌아갑니다. 열 때부터 패널을 자동으로 띄우지 않습니다. `prefers-reduced-motion`은 기존 Sheet·Morph 규칙을 따릅니다.

Android `adaptive`의 너비별 탐색 유지와 좁은 화면에서 본문을 가장자리까지 쓰기, `edge-to-edge`의 안전 영역 피하기(`env(safe-area-inset-*)`), `navigation-event`·`navigation-3`의 오버레이 복귀와 수직 열기, `jetpack-compose-performance`의 프레임 상태 갱신 억제, Impeccable `layout`의 달력 우선 읽기 순서를 웹에 적용했습니다. 새로운 애니메이션 루프나 라이브러리를 추가하지 않습니다.

## 앱과 검증

- `app/calendar/page.tsx`: 날짜 선택, 메뉴·날짜 패널, 기존 그날 내역과 월 목록.
- `CalendarCard.tsx`: 월 격자·일정 이름·선택·한 주 접기.
- `EventSheet.tsx`: 새 일정은 일정 종류에서 시작, 선택한 날짜 유지.
- 390px·넓은 화면, 빈 날·긴 제목·여러 일정·기간 일정, 앞뒤 달 선택, 메뉴의 두 목록, 선택한 날짜의 `+`, 뒤로·Escape·닫기·스와이프, 기존 완료 체크와 지출 편집을 확인합니다.
