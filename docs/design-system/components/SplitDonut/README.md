# SplitDonut — 월급이 나뉘는 곳

플랜 화면의 "월급이 나뉘는 곳" 카드입니다. 수입이 고정비·생활비·용돈·저축·남음으로 어떻게 나뉘는지 원형 그래프 하나로 보여 줍니다. 토스·뱅크샐러드의 소비 분석 원형 그래프를 참고했습니다. 홈의 "두 사람 월급의 흐름"은 그대로 PayFlow입니다.

## 구성
- **위:** 세그먼트 `[두 사람 | 현빈 | 예진]`. 사람을 고르면 그 사람 월급과 몫(`shareOf`, 공동 항목은 비율만큼)으로 다시 그립니다.
- **원:** 지름 240 기준, 반지름 84, 굵기 34입니다.
  - 순서는 고정비(`g-fixed`) → 생활비(`g-living`) → 용돈(`g-allowance`) → 저축(`g-saving`) → 남음(`g-left`)이고, 12시에서 시계 방향으로 돕니다.
  - 조각 사이에는 2.5px 틈을 둬 카드 바탕이 비칩니다.
  - 배분이 수입보다 많으면 한 바퀴를 배분 합계로 삼고 남음 조각을 그리지 않습니다.
- **가운데:** 평소에는 "두 사람 수입"과 금액(`display` 700 20px), 조각을 고르면 그 버킷 이름과 금액입니다(`aria-live`).
- **목록:** 점(10px) · 이름 · 비율(`faint`) · 금액 · 펼침 화살표. 남음은 펼치지 않습니다. 모자라면 이름이 "부족", 금액이 `negative`입니다.
- **아래 한 줄:** 두 사람이면 "공동비용은 50 : 50로 나눠요", 한 사람이면 "현빈 공동 부담 2,196,450원"(`faint`).

## 고르기
- **조각을 누르면** 그 조각이 바깥으로 8px 튀어나오고 8px 굵어지며, 나머지는 45%로 옅어집니다. 조각 바깥에 "고정비 **27%**" 말풍선(`surface`, `shadow-float`)이 뜹니다. 같은 조각을 다시 누르면 돌아옵니다.
- **목록의 이름을 누르면** 같은 조각을 고르고, 그 줄 아래에 버킷 항목(이름 · 공동/누구 · 금액, 큰 순)이 펼쳐집니다. 항목을 누르면 항목 시트가 열립니다.
- 사람을 바꾸면 고른 것과 펼친 것을 모두 닫습니다.

## 움직임·접근성
- 움직이는 것은 `transform`(튀어나옴)과 `stroke-width`, `opacity`뿐이고 `dur-swap`·`ease-out`입니다. 말풍선은 85%에서 커지며 나타납니다. `prefers-reduced-motion`이면 모두 바로 바뀝니다.
- 원 그림은 `aria-hidden`이고, 같은 일을 목록 버튼(`aria-expanded`, 남음은 `aria-pressed`)으로 할 수 있습니다. 색만으로 버킷을 말하지 않고 늘 이름과 비율을 함께 씁니다.
