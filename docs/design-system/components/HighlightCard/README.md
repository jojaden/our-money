# HighlightCard

한 화면에서 가장 중요한 소식 하나를 옅은 빛 한 색 카드로 띄우며, 회차가 있으면 단계 점을 함께 보여 줍니다.

## 언제 쓰나
- 적금·할부의 회차("전세 보증금 적금 · 4회차"), 오늘이 월급날일 때, 이번 달 첫 기록 안내
- 한 화면에 하나까지만 둡니다. 나머지는 흰 카드(`shadow-card`)로 둡니다.

## 구성
- **바탕:** `sky-50` 한 색, `radius-card`, 안쪽 `pad`입니다. 그라데이션과 그림자는 없습니다.
- **제목:** `headline`입니다.
- **단계 점:**
  - 끝난 회차는 7px `step-done`, 남은 회차는 7px `step-todo`입니다.
  - 지금 회차는 12px `accent`에 4px 옅은 후광을 두고, `dur-breathe` 박자로 후광이 넓어졌다 줄어듭니다.
  - 점 앞에는 늘 "4회차" 글자를 둡니다.
- **금액 줄:** `display` 20px/700 금액과 `faint` 설명입니다.

## 쓰는 쪽이 줄 것
- 제목, 전체 회차와 지금 회차(없으면 점 줄을 뺌), 금액, 한 줄 설명

## 하지 말 것
- 진한 색이나 그라데이션으로 바꾸지 않습니다(데이터 위에 그라데이션을 깔지 않는다).
- 강조 카드에 그림자나 링을 두지 않습니다.
- 단계가 20개를 넘으면 점 대신 "4 / 24회"처럼 글자로만 씁니다.
