# TabBar

폰 화면 아래에 떠 있는 다섯 칸 캡슐 메뉴로, 오른쪽에 따로 뜬 원형 버튼(그 화면의 주된 일)과 함께 씁니다.

## 구성
- **캡슐:** 화면 좌우·아래(안전 영역 위)에서 `nav-inset`만큼 떨어집니다. 높이 `nav-h`, `radius-chip`, `surface` 86% + blur 22px·saturate 180%, `shadow-nav`입니다.
- **칸:** 홈 `House`, 플랜 `Layers`, 체크 `ListChecks`, 가계부 `ReceiptText`, 달력 `CalendarDays`입니다. 아이콘 22px에 `tab-label` 글자를 둡니다.
- **고른 칸:**
  - Illuminating 노랑(`primary`) 알약이 위아래 5px 안쪽에서 감쌉니다. 그 위 아이콘과 글자는 진한 회색 `on-primary`입니다. 데스크톱 레일의 고른 칸도 같은 노랑입니다.
  - 칸을 바꾸면 알약이 `dur-tab`·`ease-drawer`로 미끄러집니다.
  - 누르는 동안 아이콘이 0.88로 줄었다가 `ease-press`로 돌아옵니다.
- **원형 버튼:** 캡슐에서 `nav-gap` 떨어지고, 지름 `nav-h`입니다. `primary` 채움, 흰 아이콘 26px, `shadow-float`이며 누르면 0.94입니다.
  - 화면마다 주된 일 하나만 맡습니다. 홈·가계부는 "지출 기록"(`Plus`), 달력은 "일정 추가"(`CalendarPlus`, 고른 날로 시트가 열림)입니다. 플랜·체크·설정은 주된 더하기가 없어서 버튼을 두지 않습니다(플랜은 묶음마다 추가 버튼이 있습니다).
  - **달력 첫 화면:** 달력만 보일 때는 캡슐이 아래로 내려가 숨고 원형 버튼이 가운데로 옮겨 가며 얇은 막대(224 × 52px)로 늘어납니다 — 왼쪽은 "11월 17일에 추가"(누르면 바로 쓰기로 펼침), 오른쪽은 `+`. 가운데는 하단 메뉴 실제 폭(`container-type: inline-size`, `cqw`)으로 잡습니다. 줄에서 차지하는 자리는 동그라미 그대로라(왼쪽으로만 늘어남) 숨는 캡슐이 눌리지 않습니다. 모아 보기로 내리면 제자리로 돌아옵니다([Calendar](../Calendar/README.md) "두 칸").
  - 아이콘이 바뀌면 새 아이콘이 0.6 크기·-45°에서 `dur-tab`·`ease-pop`으로 자리 잡습니다. `aria-label`은 그 일의 이름입니다.
  - 버튼이 없는 화면으로 가면 버튼이 줄어들며 빠지고(폭·간격을 `dur-tab`·`ease-drawer`로) 캡슐이 그 자리까지 넓어집니다. 알약은 칸 폭에 맞춰 같은 박자로 따라가서 옆으로 튀지 않습니다. 빠진 버튼은 누를 수 없습니다(inert).
  - 데스크톱 머리줄 버튼도 같은 규칙입니다(버튼이 없는 화면은 비웁니다).
- **폭:** 캡슐과 버튼 묶음은 최대 480px이고 가운데에 둡니다(태블릿에서 너무 길어지지 않게).
- **설정:** 캡슐에서 빠지고 위쪽 막대 오른쪽 톱니로 옮깁니다(TopBar, 종 옆). 설정 화면에서는 고른 칸이 없으므로 알약을 숨깁니다.
- **투명도 줄이기:** 캡슐 바탕이 불투명한 `surface`가 됩니다.
- **데스크톱(1024px 이상):** 56px 레일로 바꾸고 아래에 종(알림 모음)과 톱니(설정)를 둡니다.

## 쓰는 쪽이 줄 것
- 지금 페이지(`aria-current="page"`)
- 페이지 아래 여백: `nav-h + nav-inset × 2 + env(safe-area-inset-bottom)`

## 하지 말 것
- 칸을 다섯 개보다 늘리지 않습니다(달력을 더하며 네 칸에서 다섯 칸이 됐어요. 칸 폭이 좁아 글자는 세 글자 안으로).
- 원형 버튼을 캡슐 안에 넣지 않습니다.
- 한 화면에 원형 버튼과 같은 일을 하는 버튼을 또 두지 않습니다(예: 달력 그날 머리의 "+ 추가"는 원형 버튼으로 합쳤습니다).
- 캡슐을 화면 끝에 붙이지 않습니다.
