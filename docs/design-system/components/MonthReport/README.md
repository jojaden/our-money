# MonthReport — 한 달 결산

그달이 끝난 뒤 **한 장으로 돌아보는 시트**입니다(뱅크샐러드 머니리포트 참고). 숫자를 새로 계산하지 않고, 이미 있는 계산(달력 모아 보기의 `summarize`, 플랜의 `month_items`, `livingStatus`)을 한 화면에 모읍니다(`lib/report.ts` — 화면용 묶음이라 `calc.ts` 에 두지 않음).

## 어디서 여나
- 홈 "10월이 끝났어요" 카드의 **돌아보기**(전엔 체크 맨 아래 메모로 갔습니다 — 메모는 이 시트 아래 버튼으로).
- 체크 맨 아래 "10월 마무리"의 **결산 보기** — 그달이 끝난 뒤에만(지난 달을 골라 보면 언제든).

## 구성 (위에서 아래로)
1. **쓴 돈:** `hero-label` "10월에 쓴 돈" + `hero-amt` 큰 금액(산 날 기준, 할부는 전액 — 모아 보기와 같은 셈).
   - 그 아래 한 줄: "지난달보다 **120,000원** 덜 썼어요 · 기록 31건". 지난달 기록을 불러오지 않았으면 차이는 쓰지 않습니다(0 으로 보이지 않게 — 정직한 숫자).
2. **나간 돈 N원:** 고정비(플랜, 낸 금액) · 공동 생활비 · 용돈(두 사람) · 저축·투자. 줄마다 금액·비율과 얇은 `Meter`(예산 막대와 같은 모양). 0 인 칸은 뺍니다.
3. **눈에 띈 것:** 가장 많이 쓴 분류(분류 아이콘, 건수·쓴 돈의 %), 가장 큰 지출 하나(날짜·누구 돈).
4. **공동 생활비:** "예산 1,400,000원 중 1,322,700원 · **77,300원 남겼어요**"(`positive`) 또는 "N원 넘었어요"(`negative`). 예산이 없으면 뺍니다.
5. **분류·기록 자세히 보기** → 달력 모아 보기(그달 기간). 아래 고정 버튼 **10월 메모 남기기** → 체크의 마무리(그달로 옮겨).

## 하지 말 것
- 자산 순위·또래 비교처럼 두 사람 밖의 데이터가 필요한 것은 넣지 않습니다.
- 결산을 화면을 막는 팝업으로 띄우지 않습니다. 사람이 "돌아보기"를 눌렀을 때만 엽니다.
