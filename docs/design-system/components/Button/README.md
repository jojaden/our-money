# Button

할 일을 실행하는 버튼으로, 인디고 `primary` 하나에 크기와 모양만 다르게 씁니다.

## 언제 쓰나
- **블록 버튼:** 시트 맨 아래에서 결정하는 버튼입니다. 금액을 다시 보여 줍니다: "점심 12,000원 기록하기".
- **주 버튼:** 카드·설정의 저장처럼 그 자리의 주된 행동입니다.
- **보조 버튼:** "지난달에서 불러오기"처럼 곁의 행동입니다. 고스트는 취소처럼 가벼운 행동입니다.
- **위험:** 로그아웃처럼 되돌리기 어려운 행동입니다. 글자만 `negative`로 칠합니다.
- **떠 있는 버튼:** 폰에서만 "지출 기록"으로 씁니다. 데스크톱에서는 머리줄의 주 버튼으로 바꿉니다.

## 쓰는 쪽이 줄 것
- 버튼 글: 하는 일을 동사로 씁니다. 금액이 들어가면 `display` 글꼴의 고정폭 숫자로 씁니다.
- 앞 아이콘은 lucide 20px만 씁니다(떠 있는 버튼은 `Plus`).
- 확인이 필요한 행동은 페이지 안의 확인 단계를 따로 둡니다.

## 하지 말 것
- 한 화면에 블록 버튼을 둘 이상 두지 않습니다.
- 인디고 말고 다른 색 채움 버튼을 만들지 않습니다.
