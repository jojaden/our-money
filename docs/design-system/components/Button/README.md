# Button

할 일을 실행하는 버튼으로, Illuminating 노랑 `primary` 하나에 진한 회색 글자(`on-primary`)로, 크기와 모양만 다르게 씁니다.

## 언제 쓰나
- **블록 버튼:** 시트 맨 아래에서 결정하는 버튼입니다. 금액을 다시 보여 줍니다: "점심 12,000원 기록하기".
- **주 버튼:** 카드·설정의 저장처럼 그 자리의 주된 행동입니다.
- **보조 버튼:** "지난달에서 불러오기"처럼 곁의 행동입니다. 고스트는 취소처럼 가벼운 행동입니다.
- **위험:** 로그아웃처럼 되돌리기 어려운 행동입니다. 글자만 `negative`로 칠합니다.
- **떠 있는 버튼:** 폰에서만 "지출 기록"으로 씁니다. 데스크톱에서는 머리줄의 주 버튼으로 바꿉니다.
- **둥근 유리 버튼:** 44px 원, `glass` 바탕에 뒤를 20px 흐리고 `shadow-float`를 줍니다. 아이콘은 22px `text`입니다. 지갑·카드 상세 위쪽의 닫기(`X`)·추가(`Plus`)에 씁니다.
- **유리 캡슐:** 같은 유리 위에 아이콘 버튼 둘을 붙여 한 캡슐로 묶습니다(찾기 + `…`, 고치기 + `…`). 셋 넘게 묶지 않습니다.
- **회색 알약:** `tab-active-bg` 바탕, `text` 600 16px, 높이 44px입니다. 타일 안에서 "결제했어요"·"옮겼어요"처럼 그 자리에서 끝내는 행동에 씁니다.
  - 누르면 같은 자리의 64px 체크 원(`tab-active-bg`)으로 바뀌며 `dur-pop`·`ease-pop`으로 튑니다.
  - 글도 결과로 바꿉니다("다 냈어요").
  - 되돌리기는 토스트로 줍니다.

## 쓰는 쪽이 줄 것
- 버튼 글: 하는 일을 동사로 씁니다. 금액이 들어가면 `display` 글꼴의 고정폭 숫자로 씁니다.
- 앞 아이콘은 lucide 20px만 씁니다(떠 있는 버튼은 `Plus`, 유리 버튼은 22px).
- 글 없는 유리 버튼에는 `aria-label`을 붙입니다("닫기", "카드·계좌 추가").
- 확인이 필요한 행동은 페이지 안의 확인 단계를 따로 둡니다.

## 하지 말 것
- 한 화면에 블록 버튼을 둘 이상 두지 않습니다.
- 노랑 말고 다른 색 채움 버튼을 만들지 않습니다. 노랑 버튼에 흰 글자를 쓰지 않습니다.
- 유리 버튼을 흰 카드 안에 두지 않습니다. 유리는 화면 바탕이나 그림 위에 떠 있을 때만 씁니다(카드 안에서는 회색 알약).
