# HoldMenu — 꾹 눌러 여는 메뉴

목록의 한 줄을 **아이폰의 컨텍스트 메뉴처럼** 꾹 누르면, 뒤가 흐려지며 그 줄이 카드로 떠오르고 줄 오른쪽 끝에 맞춘 메뉴가 나옵니다. 달력의 날짜 패널과 아래 모아 보기의 모든 줄(일정·할 일·D-day·나갈 돈·들어올 돈·쓴 돈)에 쓰고, 메뉴는 줄마다 다릅니다(아래 표). 짧게 누르기는 그대로입니다(일정 고치기). 메뉴의 일은 다른 길로도 할 수 있어야 합니다(고치기·삭제는 일정 시트에도 있음).

## 열기
- **손가락:** 0.45초 꾹 누르기. 누르는 동안 줄이 0.1초 뒤부터 0.96까지 살짝 눌려 들어가고, 차면 짧은 진동(되는 기기만)과 함께 메뉴가 뜹니다. 그사이 8px 넘게 움직이면 취소되고 줄은 제자리로 돌아옵니다(스크롤·시트 끌기는 그대로).
- **마우스·키보드:** 오른쪽 클릭, 키보드 메뉴 키·Shift+F10(`contextmenu`). 안드로이드가 길게 누르기로 보내는 `contextmenu` 도 같은 메뉴를 한 번만 엽니다. 브라우저 메뉴·글자 선택 말풍선은 띄우지 않습니다(`-webkit-touch-callout: none`).

## 모양
- **뒤:** 화면 전체를 `scrim` 55% + 흐림 14px 로 덮습니다(흐림 반경은 움직이지 않고 미리 흐린 층의 투명도만).
- **들린 줄:** 원래 줄을 그대로 베낀 카드(`surface`, `radius-inner`, `shadow-float`, 양옆 12px 넓혀 글자는 제자리·가장자리와 12px)가 같은 자리에서 0.96 → 1.03 → 1 로 떠오릅니다(`dur-tab`·`ease-out`). 원래 줄은 그동안 숨깁니다.
- **메뉴:** 폭 232px, `radius-inner`, `surface` 90% + 흐림 22px, `shadow-float`. 줄 높이 48px, 글자 16px 500, 오른쪽에 20px 아이콘. 줄 사이는 0.6px `rule`. 지우기(`negative`)는 6px `well` 틈으로 떼어 맨 아래에 둡니다. 순서는 수정 · 복사 · 공유 | 삭제.
  - 들린 줄 **오른쪽 끝에 맞춰 바로 아래**(10px) 두고, 그 모서리(위 오른쪽)에서 0.4 → 1 로 튀어나옵니다(`dur-tab`·`ease-pop`).
  - 아래에 자리가 모자라면 줄이 위로 비켜 올라가고, 그래도 안 되면 메뉴를 줄 위에 둡니다. 화면 가장자리·안전 영역(`env(safe-area-inset-*)`)에서 12px 안쪽.
- **닫기:** 메뉴는 0.7 로 오므라들며 사라지고(160ms, `ease-out` — 시작이 느린 `ease-in` 은 굼떠 보여서), 줄은 제자리로 내려앉고(`dur-swap`), 뒤는 걷힙니다. 그다음 원래 줄을 다시 보입니다.

## 고르기·닫기
- 손가락을 떼지 않고 메뉴로 끌면 손가락 밑 줄이 `well` 로 밝아지고, 거기서 떼면 그 일을 합니다. 메뉴 밖에서 떼면 메뉴는 남아 있고 다시 눌러 고릅니다(뗀 순간 브라우저가 만드는 click 은 삼킴).
- 흐린 바탕 누르기·뒤로 가기·Esc 는 **메뉴만** 닫습니다(아래 날짜 패널은 그대로). 키보드로 열면 첫 줄에 포커스, ↑↓·Home·End 로 옮기고 Enter(메뉴 줄은 `tabIndex=-1`), Tab 이면 메뉴를 닫습니다(흐린 막 뒤로 빠지지 않게). 닫으면 포커스는 그 줄로 돌아옵니다.
- 공유처럼 누른 순간에 해야 하는 일은 바로 하고, 나머지(수정·복사·삭제)는 메뉴가 쌓은 뒤로 가기 기록이 빠진 다음에 합니다 — 이어서 날짜 패널을 닫고 일정 시트를 여는 기록이 꼬이지 않게.

## 어디서, 무엇이 뜨나
달력 화면의 줄은 모두 꾹 누를 수 있고, 메뉴는 그 줄의 성격에 맞는 일만 둡니다(`components/holdActions.ts`). 날짜 패널 안이면 다른 화면으로 갈 때 패널을 먼저 닫고, 수정·복사는 끝나면 패널로 돌아옵니다.

| 줄 | 어디 | 메뉴 |
|---|---|---|
| 일정 | 날짜 패널, 모아 보기 "일정" | 수정 · 복사 · 공유 \| 삭제 |
| 할 일 | 날짜 패널, 모아 보기 "할 일" | 완료(완료 취소) · 수정 · 복사 · 공유 \| 삭제 |
| D-day | 날짜 패널, 모아 보기 "D-day" | 수정 · 복사 · 공유(남은 날 포함) \| 삭제 |
| 나갈 돈 — 이체·납부 | 날짜 패널, 모아 보기 "할 일" | 완료(완료 취소) · 체크에서 보기 · 플랜에서 보기 |
| 나갈 돈 — 카드값·정산 | 날짜 패널, 모아 보기 "할 일" | 완료(완료 취소) · 체크에서 보기 |
| 들어올 돈 — 월급날 | 날짜 패널 | 체크에서 나누기 · 플랜에서 월급 고치기 · 월급날 바꾸기 |
| 쓴 돈 | 날짜 패널 | 수정 \| 삭제 |

- **복사:** 같은 내용(종류·제목·시간·기간·반복·누구·알림·메모)으로 **새 일정** 시트를 엽니다. 날짜만 바꿔 저장하면 하나 더 생깁니다.
- **공유:** 앱은 일정 내보내기와 같은 .ics 공유 창(받는 쪽이 캘린더에 바로 넣음), 브라우저는 기기 공유 창(제목 · 날짜·시간 · D-day · 메모 글). 둘 다 안 되면 그 글을 클립보드에 넣고 "일정 내용을 복사했어요".
- **삭제:** 일정·지출 시트의 삭제와 같습니다. 묻지 않고 지우고 토스트의 "되돌리기"로 살립니다. 반복 일정은 통째로 지웁니다.
- 체크 화면·홈·플랜·가계부의 줄에는 두지 않습니다 — 그 화면들은 카드를 꾹 눌러 옮기기([Arrange](../Arrange/README.md))가 같은 손짓을 씁니다.
- 줄을 감싼 `.hold` 가 목록 구분선(`.rows > .row + .row`)을 끊지 않도록 `.rows > .hold + .hold > .row` 에도 같은 선을 긋습니다.

## 시트 안에서
날짜 패널은 vaul 시트라 메뉴를 **그 시트 안에** 그립니다(바깥에 그리면 시트가 바깥 누르기로 닫히고 포커스를 끌어감). 시트는 `will-change: transform` 이라 `position: fixed` 의 기준이 되므로, 메뉴 층을 시트 위치만큼 거꾸로 옮겨 화면 전체를 덮습니다. 메뉴 위의 손가락으로 시트가 끌려 내려가지 않게 `data-vaul-no-drag`. 넓은 화면(1024px 이상)은 시트가 둥글게 잘려 있어 흐림·메뉴가 시트 안에 머뭅니다.

## 하지 말 것
- 꾹 누르기를 그 일의 유일한 길로 두지 않습니다. 키보드로 메뉴를 여는 길은 메뉴 키·Shift+F10 뿐이라(Mac·iPad·폰 키보드엔 없음) 메뉴에만 있는 일을 두지 않습니다 — 일정의 복사·공유도 일정 시트 아래에 있습니다(고치던 중에는 저장한 뒤).
- 흐림 반경·그림자를 움직이지 않습니다(프레임 비용). transform·opacity 만.
- 메뉴를 손가락 밑에 띄우지 않습니다 — 뗄 때 바로 눌립니다. 줄 아래(또는 위)에 둡니다.

`prefers-reduced-motion` 이면 움직임 없이 바로 뜨고 닫힙니다. `prefers-reduced-transparency` 면 흐림 대신 불투명한 `scrim`·`surface`. Android `navigation-event`(뒤로 가기는 맨 위 겹 하나만 닫음), `jetpack-compose-performance`(합성 속성만 움직이기), Astryx `ContextMenu`·`useLongPress`(움직이면 취소, 뗀 자리의 줄을 고름, 다른 길도 남기기)를 웹에 맞춰 적용했습니다.
