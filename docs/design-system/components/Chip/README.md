# Chip

목록을 사람·분류로 거르는 알약 버튼으로, 고른 칩은 옅은 인디고 바탕에 진한 인디고 글자가 됩니다.

## 구성
- **모양:** 38px 높이, `radius-chip`, `well` 바탕, `muted` 글자 14.5px/600이며 테두리는 없습니다.
- **고른 칩:** `accent-soft` 바탕, `accent-ink` 글자, 1.5px 옅은 `accent` 안쪽 링입니다(전체 / 공동 / 현빈 / 예진).
- **앞 표시:** 사람이나 카테고리 칩은 22px 동전 반쪽 표시(사람 `-soft` 바탕)나 카테고리 동그라미를 앞에 둡니다.
- **누름:** 0.95로 줄었다가 스프링으로 돌아옵니다.

## 쓰는 쪽이 줄 것
- 칩 이름, 고름 상태(`aria-pressed`), 필요하면 앞 표시

## 하지 말 것
- 고른 칩을 `primary`로 꽉 채우지 않습니다. 꽉 찬 인디고는 누르는 버튼의 모양입니다.
- 기간처럼 범위를 고르는 데는 칩 대신 TextTabs를 씁니다.
