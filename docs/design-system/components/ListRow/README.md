# ListRow

묶음 목록의 한 줄로, 앞 표시·제목·보조 줄·금액·상태 알약을 한 줄에 놓습니다.

## 구성
- **앞 표시:** 40px 동그라미입니다. 사람 동전 반쪽(`a-soft`/`b-soft`/`joint-soft` 바탕 위 26px, 공동은 동전 전체), 카테고리 동그라미, 체크 링 중 하나를 씁니다.
- **가운데:** `row-title`과 `meta`·`faint` 보조 줄입니다.
- **끝:** `row-amount`(고정폭 숫자)와 날짜나 상태 알약입니다.
- **구분선:** 0.6px `rule` 선을 `list-inset`(52px)부터 긋습니다.
- **누름:** 줄 전체에 `well` 채움을 주고 0.98로 줄입니다. 마우스 hover는 `raised`입니다. 방금 저장한 줄은 `accent-soft` 빛으로 들어옵니다.

## 쓰는 쪽이 줄 것
- 누구 돈인지(a / b / 공동), 제목, 보조 줄, 금액, 상태(지남·곧·완료·보통, 늘 글자와 함께)

## 하지 말 것
- 줄 전체를 사람 색으로 칠하지 않습니다.
- 평범한 지출 금액을 빨갛게 쓰지 않습니다.
- 구분선을 끝에서 끝까지 긋지 않습니다.
