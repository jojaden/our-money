# Loading

이 기기에 저장해 둔 내용이 없을 때 데이터를 받는 동안 보여 주는 화면입니다. 앱 바탕 한가운데에서 두 사람의 동전이 천천히 다가가 겹쳤다가 살짝 멀어지기를 되풀이합니다.

## 언제 쓰나
- 처음 로그인한 뒤 첫 데이터를 받는 동안 씁니다. 다시 열 때는 저장본으로 바로 그리므로 뜨지 않습니다.
- 처음 로그인에 달력 표만 먼저 왔을 때, 달력이 아닌 화면은 나머지가 올 때까지 이 화면입니다.
- 탭을 옮기거나 저장할 때는 쓰지 않습니다. 그때는 화면을 먼저 바꾸고 뒤에서 저장합니다.

## 구성 (Login 무대를 작고 조용하게)
- **바탕:** 앱과 같은 `ground`입니다. 상태 막대 색도 그대로 둬서, 데이터가 오면 화면만 바뀌고 색은 튀지 않습니다(edge-to-edge). Login의 따뜻한 무대 바탕은 쓰지 않습니다.
- **자리:** 브랜드와 글을 화면 한가운데(아래 탭 막대 높이만큼 위로)에 둡니다. 브랜드는 Login의 72% 크기입니다.
- **브랜드 동전:**
  - 앱 아이콘을 입체로 옮겼습니다. 위에 `primary` 지붕(선 10px, 둥근 끝, 같은 색 옅은 그림자)이 있습니다.
  - 그 아래 104px 동전 둘이 70px 간격으로 겹칩니다. 현빈은 `a`, 예진은 `b`입니다.
  - 동전은 왼쪽 위에서 빛을 받은 둥근 면입니다. 같은 색 22% → 58% → 88%를 `coin-glint`(흰빛)와 섞은 원형 그라데이션에, 안쪽 아래 `-ink` 그림자와 아래로 같은 색 그림자를 둡니다.
  - 겹친 자리는 `coin-glint` 흰 렌즈입니다(앱 아이콘과 같음). 다크에서도 흰빛이라 검은 구멍처럼 보이지 않습니다.
- **바닥 그림자:** 동전 아래 176×22px 타원(`text` 15%)입니다.
- **곁의 동전:** 두지 않습니다(Login에만).
- **글:** 브랜드 아래 `muted` 17px 굵기 600 한 줄 "우리 집 기록을 불러오고 있어요". 기다림이 짧아 큰 제목과 설명은 두지 않습니다.
- **접근성:** 화면 전체가 `role="status"`입니다. 무대는 `aria-hidden`입니다.

## 움직임
- 두 동전이 `dur-breathe`(4초) 한 박자에 ±10px 벌어졌다가 맞붙습니다(`ease-breathe`).
- 흰 렌즈는 두 동전 사이 거리만큼 같이 움직여, 겹친 자리가 늘 정확합니다.
- 이 화면에서 계속 움직이는 것은 동전 둘 하나뿐입니다.
- 움직임 줄이기 설정이면 맞붙은 상태로 멈춥니다.

## 쓰는 쪽이 줄 것
- 8초가 지났는지

8초가 넘으면 `faint` 15px 한 줄 "연결이 느려요. 조금만 기다려 주세요"를 더합니다.

## 하지 말 것
- 진행 막대나 퍼센트를 두지 않습니다. 끝을 모르는 기다림이기 때문입니다.
- 동전 대신 마스코트나 캐릭터를 넣지 않습니다.
- 곁의 동전을 셋 넘게 늘리거나 움직이지 않습니다.
- 0.6초 안에 끝나는 로딩에는 띄우지 않습니다(깜빡임 방지).
- "펼치는 중"처럼 무엇을 하는지 흐린 말을 쓰지 않습니다. 기다리는 대상을 그대로 말합니다.

## 앱에서
- 바탕은 바로 그리고, 동전과 글은 0.6초 뒤에 0.32초 동안 나타납니다(CSS 지연, 타이머 없음). 0.6초 안에 끝나면 앱 바탕만 스쳐 보이지 않습니다.
- 8초 타이머 하나로 "연결이 느려요" 줄을 더합니다.
- 움직이는 것은 동전 둘의 transform 뿐입니다(흐림 필터 장식은 빼서 그리기 비용이 없습니다).
