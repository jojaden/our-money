# Loading

앱을 처음 열어 데이터를 받는 동안 보여 주는 화면입니다. 따뜻한 무대 위에서 두 사람의 동전이 천천히 다가가 겹쳤다가 살짝 멀어지기를 되풀이합니다. "두 사람의 기록을 맞추고 있어요"를 그대로 그림으로 옮긴 것입니다.

## 언제 쓰나
- 로그인 뒤 첫 데이터를 받는 동안만 씁니다.
- 탭을 옮기거나 저장할 때는 쓰지 않습니다. 그때는 화면을 먼저 바꾸고 뒤에서 저장합니다.

## 구성 (Login과 같은 무대)
- **바탕:** 가운데가 밝은 원형 그라데이션입니다. `surface`에 가까운 `warm-50`에서 `warm-50`을 지나 가장자리 `warm-100`으로 퍼집니다(Alan 첫 화면의 복숭아빛).
- **브랜드 동전:**
  - 앱 아이콘을 입체로 옮겼습니다. 위에 `primary` 지붕(선 10px, 둥근 끝, 같은 색 옅은 그림자)이 있습니다.
  - 그 아래 104px 동전 둘이 70px 간격으로 겹칩니다. 현빈은 `a`, 예진은 `b`입니다.
  - 동전은 왼쪽 위에서 빛을 받은 둥근 면입니다. 같은 색 22% → 58% → 88% 원형 그라데이션에, 안쪽 아래 `-ink` 그림자와 아래로 같은 색 그림자를 둡니다.
  - 겹친 자리는 흰 렌즈입니다(앱 아이콘과 같음).
- **바닥 그림자:** 동전 아래 176×22px 타원(`text` 15%)입니다.
- **곁의 동전:** 멀리 흐린 금빛 동전(76px, 흐림 5px)이 왼쪽 가장자리에 걸치고, 가까이 기운 작은 동전(32px)이 오른쪽에 있습니다. 색은 `g-allowance`이고 움직이지 않습니다.
- **글:** 무대 아래 가운데에 `moment-title` 제목("가계부를 펼치는 중이에요")과 `muted` 17px 설명("두 사람의 기록을 맞추고 있어요")을 둡니다.
- **접근성:** 화면 전체가 `role="status"`입니다. 무대는 `aria-hidden`입니다.

## 움직임
- 두 동전이 `dur-breathe`(4초) 한 박자에 ±10px 벌어졌다가 맞붙습니다(`ease-breathe`).
- 흰 렌즈는 두 동전 사이 거리만큼 같이 움직여, 겹친 자리가 늘 정확합니다.
- 이 화면에서 계속 움직이는 것은 동전 둘 하나뿐입니다.
- 움직임 줄이기 설정이면 맞붙은 상태로 멈춥니다.
