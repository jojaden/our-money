# StepTrack

몇 개 안 되는 할 일(최대 8개)의 진행을 **칸 나눈 가로 막대**로 보여 줍니다. 할 일 하나가 한 칸입니다(README "숫자와 막대": 전체 중 몇 개 끝냈나 → 숫자 + 진행 막대).

## 언제 쓰나
- 체크 화면 요약의 "11월 옮길 돈 3 / 6건", 월급날 묶음 하나의 진행처럼 단계가 8개 이하일 때 씁니다.
- 단계가 더 많으면(적금 12회차 등) HighlightCard의 단계 점을 씁니다.
- **체크 화면 월급날 카드:** 진행 막대를 카드 머리로 쓰고, 그 아래에 할 일 줄을 바로 둡니다. 줄이 카드 안에 있으니 `ChevronRight`는 빼고, 제목 오른쪽에는 월급날 날짜를 둡니다. 메타 줄이 "현빈 급여통장에서"를 말하므로 이체 줄 제목은 도착 계좌만 씁니다. 옮길 돈이 8건을 넘으면 막대 없이 메타 줄만 둡니다.

## 구성
- **섹션 이름표:** 카드 위에 `small`·`faint`로 "이번 달 할 일"을 둡니다.
- **카드:** 흰 카드(`shadow-card`)에 제목(17px/600)과 오른쪽 `ChevronRight`를 둡니다.
- **메타 줄:** `Target` 아이콘과 "3 / 6건 옮김"입니다. 숫자가 먼저, 막대는 그 아래입니다.
- **진행 막대:**
  - 높이 8px(`Meter` thin과 같음), 칸 사이 4px, 칸마다 `radius-chip`입니다.
  - 끝낸 칸은 `accent`, 남은 칸은 `well`입니다. 체크 표시·원은 두지 않습니다(체크는 아래 할 일 줄에 있습니다).
- **아래 줄:** `Clock` 아이콘과 기한·남은 금액입니다.
- **움직임:** 할 일을 끝내면 그 칸이 왼쪽에서 `dur-value`·`ease-value`로 차오르고, 되돌리면 같은 박자로 빠집니다. 칸 폭만 한 띠를 `translateX`로 밀어 넣어 레이아웃 없이 움직입니다. 움직임 줄이기 설정이면 바로 바뀝니다.

## 쓰는 쪽이 줄 것
- 제목, 전체·끝낸 수, 기한 문장, 누르면 갈 곳

## 하지 말 것
- 9칸 이상으로 나누지 않습니다.
- 칸마다 다른 색을 쓰거나 그라데이션으로 번지게 하지 않습니다.
- 체크 원과 이음선으로 되돌리지 않습니다. 같은 "진행"은 어디서나 막대입니다.
