# StepTrack

몇 개 안 되는 할 일(최대 8개)의 진행을 체크 원과 이음선으로 보여 주는 카드입니다.

## 언제 쓰나
- 체크 화면 요약의 "11월 옮길 돈 3 / 6건", 월급날 묶음 하나의 진행처럼 단계가 8개 이하일 때 씁니다.
- 단계가 더 많으면(적금 12회차 등) HighlightCard의 단계 점을 씁니다.
- **체크 화면 월급날 카드:** 진행선을 카드 머리로 쓰고, 그 아래에 할 일 줄을 바로 둡니다. 줄이 카드 안에 있으니 `ChevronRight`는 빼고, 제목 오른쪽에는 월급날 날짜를 둡니다. 메타 줄이 "현빈 급여통장에서"를 말하므로 이체 줄 제목은 도착 계좌만 씁니다. 옮길 돈이 8건을 넘으면 진행선 없이 메타 줄만 둡니다.

## 구성
- **섹션 이름표:** 카드 위에 `small`·`faint`로 "이번 달 할 일"을 둡니다.
- **카드:** 흰 카드(`shadow-card`)에 제목(17px/600)과 오른쪽 `ChevronRight`를 둡니다.
- **메타 줄:** `Target` 아이콘과 "3 / 6건 옮김"입니다.
- **진행선:**
  - 20px 원과 4px 이음선입니다.
  - 끝낸 단계는 `primary` 원에 흰 `Check`, 그 앞 이음선도 `primary`입니다.
  - 남은 단계는 `well` 테두리 빈 원과 `well` 이음선입니다.
- **아래 줄:** `Clock` 아이콘과 기한·남은 금액입니다.
- **움직임:** 단계를 끝내면 이음선이 `dur-value`로 차오르고, 원이 `ease-pop`으로 한 번 튑니다. 처음 그릴 때는 튀지 않습니다.

## 쓰는 쪽이 줄 것
- 제목, 전체·끝낸 수, 기한 문장, 누르면 갈 곳

## 하지 말 것
- 9단계 이상을 원으로 늘어놓지 않습니다.
- 단계마다 다른 색을 쓰지 않습니다.
